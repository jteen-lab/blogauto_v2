# AI 모델 카탈로그 — 동기화·표시·경고

> 모델 목록을 DB 한 곳으로 모으고, 제공자 API 에서 주기적으로 갱신한다.
> 화면은 하드코딩 대신 이 목록을 받아 쓴다.
> 계획서: `docs/plans/ai_model_catalog_sync.md`

## 동기화

```mermaid
flowchart TD
    A[동기화 시작<br/>자동 주기 또는 지금 갱신] --> B[제공자 순회]
    B --> C{등록된 키 있나?}
    C -->|없음| D[건너뜀 — 에러 아님]
    C -->|있음| E[제공자 모델 목록 API 호출]
    E --> F{성공?}
    F -->|실패| G[해당 제공자만 실패 기록<br/>나머지는 계속]
    F -->|성공| H[용도 분류<br/>Google=supportedGenerationMethods<br/>그 외=이름 규칙]
    H --> I[DB 대조]
    I --> J[신규 → 추가]
    I --> K[여전히 있음 → last_seen 갱신]
    I --> L[사라짐 → is_available=false<br/>행은 지우지 않는다]
    J --> M[결과 집계]
    K --> M
    L --> M
    M --> N[동작 로그: 신규 n / 사라짐 n / 유지 n]
    D --> B
    G --> B
```

**사라진 모델을 지우지 않는 이유**: 지우면 그 모델을 쓰던 블로그 설정이
무엇을 가리켰는지 알 수 없게 된다. `is_available=false` 로 남겨야
"지원 종료" 표시와 경고가 가능하다.

## 화면 표시

```mermaid
flowchart TD
    A[블로그 AI 탭 진입] --> B[GET /api/v1/ai-models?capability=text]
    B --> C[제공자별 그룹핑]
    C --> D{저장된 모델이 목록에 있나?}
    D -->|있음| E[정상 표시]
    D -->|없음| F[목록 맨 위에 추가<br/>'지원 종료' 표시 + 선택 유지]
    E --> G[요금 표시<br/>입력/출력 100만 토큰당]
    F --> G
    G --> H{tier 배지}
    H -->|flagship| I[최고 성능]
    H -->|value| J[가성비]
    H -->|없음| K[배지 없음]
```

**저장된 값을 지우지 않는 이유**: 목록에서 사라졌다고 선택을 비우면
사용자가 모르는 사이 다른 모델로 글이 나간다.

## 경고

```mermaid
flowchart TD
    A[동기화 완료] --> B[블로그 ai_config 순회]
    B --> C{쓰는 모델이 is_available=false?}
    C -->|예| D[WARNING 로그 + 설정 화면 배너]
    C -->|아니오| E{shutdown_date 임박?}
    E -->|예| F[종료 예정 안내]
    E -->|아니오| G[정상]
    D --> H[사람이 직접 교체]
    F --> H
```

**자동 교체하지 않는다**: 모델이 바뀌면 글 품질과 요금이 달라진다.
gpt-4o-mini → gpt-4.1-mini 전환에서 분량이 1,618자 → 3,542자로 달라졌다.

## 요금 관리

모델 목록 API 어디에도 요금 필드가 없다(실측 확인). `ai_model_prices` 에
우리가 관리하고, 갱신일을 함께 표시해 오래된 값인지 알 수 있게 한다.

## 단계

| 단계 | 산출물 |
|---|---|
| 1 | 테이블 2개 + 동기화 서비스 + 조회 API |
| 2 | `지금 갱신` 버튼 + 결과 요약 |
| 3 | 블로그 AI 탭 교체 (요금·배지 표시) |
| 4 | 나머지 화면 5곳 교체 |
| 5 | 주기 동기화(사용자 설정) + 사라짐 경고 |
