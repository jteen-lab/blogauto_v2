### 발견된 문제 2건

**(1) 레시피노트의 robots.txt 가 남의 사이트맵을 가리킨다**

```
https://recipenote4.blogspot.com/robots.txt
  Sitemap: https://soojaknam.blogspot.com/sitemap.xml   ← 수작남
```

블로거 설정에 커스텀 robots.txt 를 넣으면서 수작남 것을 그대로 복사한 것으로
보인다. 구글이 레시피노트 사이트맵을 찾지 못한다.
→ 블로거 관리 화면에서 `recipenote4` 로 고쳐야 한다(우리 앱이 건드리는 값이 아니다).

**(2) 블로거 6개 전부 네이버 소유확인이 없다**

`naver-site-verification` 메타태그가 0건이다. 워드프레스는 3개 있고
굿팁꿀팁만 없다.

## 3. 네이버가 안 나오는 이유 — 우리 문제가 아닌 부분이 크다

네이버 웹문서 검색 API로 일반 질의 8개(800건)의 출처를 조사했다.

| 출처 | 건수 | 비중 |
|---|---|---|
| 기관·기업 공식 사이트 | 760 | 95.0% |
| 네이버 자체 서비스 | 39 | 4.9% |
| **blogspot** | **1** | **0.1%** |
| 티스토리 | 0 | 0% |

상위 도메인: 만개의레시피(92) · 한국관광공사(40) · 비짓제주(32) · 우리은행(30) ·
삼성서비스(20) · 마이크로소프트(25) · 나무위키(14) · 미래에셋(8)

**네이버 웹문서는 사실상 기관·기업 공식 사이트로 채워진다.** 개인 블로그는
플랫폼을 막론하고 거의 들어가지 못한다(티스토리조차 0건).

또한 각 사이트의 최신 글 제목을 **그대로** 검색해도:

| 블로그 | 20건 중 우리 사이트 |
|---|---|
| 인생꿀팁 | 1건 |
| 굿팁꿀팁·꿀팁대백과사전·잡학다식 | **0건** |

### 결론

네이버 미노출은 **두 원인이 겹쳐 있다.**

1. **구조적 한계(우리가 못 바꾸는 것)** — 네이버 웹문서는 공신력 있는 사이트
   위주다. 개인 워드프레스·블로거가 상위에 들어가기는 매우 어렵다.
2. **우리 쪽 누락(바꿀 수 있는 것)** — 블로거 6개 소유확인 없음, 굿팁꿀팁 없음,
   수집 요청 미실시.

## 4. 지속 운영 방안 — 같은 문제가 반복되지 않으려면

지금 필요한 것은 한 번의 청소가 아니라 **구조**다. 아래는 블로그오토가
계속 돌아도 같은 상태로 가지 않게 하는 장치들이다.

### 4-1. 색인 결과를 발행량에 되먹인다 (가장 중요)

**지금은 색인이 0이어도 발행량이 그대로다.** 색인 점검 기능은 있지만
그 결과가 발행 결정에 전혀 반영되지 않는다. 그래서 크롤 수요가 죽은
사이트에 계속 글이 쌓였다.

```
색인률 = 최근 30일 발행 중 indexed 비율

  30% 이상 → 현재 속도 유지
  10~30%   → 발행량 절반
  10% 미만 → 하루 1개로 제한 + 화면 경고
  0% (30일) → 발행 중단 + "품질 점검 필요" 안내
```

색인률이 회복되면 자동으로 속도를 되돌린다. 성장 프로파일이 이미 단계별
발행량을 갖고 있으므로, 그 위에 **색인률 상한**을 얹는 형태가 자연스럽다.

### 4-2. 형제 사이트 주제 중복 차단을 기본값으로

**이미 기능이 있는데 꺼져 있었다.**

| 모듈 | exclude_sibling_titles |
|---|---|
| 라이프인포 | true |
| 슈마즈·레시피노트 | false |
| **나머지 12개 전부** | **미설정** |

doooit082 계열 4개가 전부 미설정이라 **105종 제목이 사이트 간 중복 게재**됐다
(「자리톡 월세환급」 6회, 「소고기 미역국 레시피」 4회).

→ 기본값을 `true` 로 바꾸고, 같은 도메인·같은 소유자 블로그를 자동으로 형제로
묶는다. 지금은 사용자가 켜야만 동작한다.

### 4-3. 발행 전 품질 게이트

생성된 글이 아래 중 하나라도 걸리면 **발행하지 않고 보류**한다.

| 검사 | 기준 | 근거 |
|---|---|---|
| 분량 | 본문 2,000자 미만 | 잡학다식이 중앙값 1,588자 |
| 제목 중복 | 형제 사이트에 같은 제목 존재 | 105종 중복 |
| 사실 밀도 | 전화번호·연봉·영업시간 등 검증 불가 수치가 핵심인 글 | 라이프인포 146건 |
| 구조 | H1 중복, 내부링크 과다 | §4-4 |

보류된 글은 목록에 남겨 사용자가 확인·재생성할 수 있게 한다. 조용히 버리면
왜 발행이 안 되는지 알 수 없다.

### 4-4. 생성 결과의 구조 문제를 발행 전에 잡는다

**H1 중복** — 테마가 `<h1>제목</h1>` 을 출력하는데 본문에도 `# 제목` 이 들어가
같은 문장이 두 번 보인다. 프롬프트가 `STEP 1 ▸ H1(#) 타이틀` 을 요구하기 때문이다.
→ 플랫폼별로 본문 H1을 넣을지 결정하고, 발행 직전에 중복이면 제거한다.

**내부링크 과다** — `intro_count: 5` + `conclusion_count: 5` 로 글마다 10개가
들어간다. 홈트 글 도입부에 레몬디톡스·일본여행 환전 링크가 붙는다.
→ 기본값을 2+3 수준으로 낮추고, **유사도 임계값을 넘지 못하면 링크를 넣지 않는다**
(지금은 수를 채우려고 관련 없는 글을 끌어온다).

### 4-5. 사이트마다 니치를 다르게 강제

지금 doooit082 계열 4개는 주제 구성이 사실상 같다 — 고객센터·효능·재테크·
여행·건강이 전부 섞여 있어 사이트마다 무엇을 다루는 곳인지 구분되지 않는다.

니치 강제 기능은 이미 있다(`niche_enabled` + `niche_topic_ids`). 애드센스
승인용으로만 쓰고 있는데, **평상시에도 사이트별로 다른 니치를 잡아** 형제
사이트끼리 주제가 겹치지 않게 한다.

### 4-6. 새 블로그 등록 시 점검 항목 자동 확인

레시피노트의 robots.txt 오류 같은 것을 등록 시점에 잡는다.

- robots.txt 의 사이트맵이 **자기 도메인**을 가리키는가
- 네이버 소유확인 메타태그가 있는가
- GSC 속성이 등록돼 있는가(굿팁꿀팁·꿀팁대백과사전은 지금 측정조차 안 된다)

연결 테스트에 이 검사를 추가하면 등록할 때 바로 드러난다.

## 5. 네이버 대응 방안

### 할 수 있는 것

| 조치 | 효과 |
|---|---|
| 블로거 6개 + 굿팁꿀팁 **소유확인 등록** | 최소 조건. 지금은 이것조차 없다 |
| 사이트맵 제출 + **수집 요청**(하루 50개 수동) | 네이버는 자동 API가 없다 |
| IndexNow 제출 | 네이버가 참여한다. 다만 워드프레스만 가능 |

### 알아 둘 한계

- **IndexNow 는 블로거에서 구조적으로 불가능하다.** 키 파일을 호스트 루트에
  올려야 하는데 blogspot.com 에는 올릴 수 없다.
- **네이버 수집 요청은 자동화할 수 없다.** 공개 API가 없어 사람이 눌러야 하고
  하루 50개 제한이다.
- **웹문서 노출 자체가 어렵다.** 위 조사대로 개인 블로그는 0.1% 수준이다.

### 현실적인 판단

네이버에서 개인 블로그로 웹문서 노출을 노리는 것은 **투입 대비 회수가 낮다.**
네이버 유입이 목표라면 네이버 블로그를 별도로 운영하는 편이 구조에 맞는다.
지금 자산(워드프레스·블로거)은 **구글 색인 회복에 집중**하고, 네이버는
소유확인·사이트맵 같은 기본만 갖춰 두는 것을 권한다.

## 7. 정직하게 덧붙임

- **색인 회복을 보장할 수 없다.** 구글은 회복 시점을 알려주지 않으며 수 주\~수
  개월이 걸린다. 위 방안은 "더 나빠지지 않게 하고 회복 가능한 상태로 되돌리는"
  것이지 색인을 되살리는 스위치가 아니다.
- **수동 조치 여부는 사용자가 GSC 에서 확인해야 한다.** API로는 알 수 없다.
  걸려 있다면 재검토 요청이 먼저다.
- 굿팁꿀팁·꿀팁대백과사전은 **GSC 속성이 없어 지금 아무것도 측정되지 않는다.**
  다른 진단보다 이 등록이 먼저다.
