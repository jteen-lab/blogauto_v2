### 취업/자격증으로 정한 이유

- 승인 준비 블로그 중 아무도 쓰지 않는다.
- YMYL 이 아니다. AI 생성 글에 가장 관대한 영역이다.
- 자격증 · 직업 정보 · 취업 정보 세 갈래가 하나의 이야기로 묶인다.

### 일부러 뺀 것

같은 토픽의 **구인구직 사이트(42건)** 와 **연봉·처우** 는 넣지 않았다.
제목이 이런 식이다.

```
대구 구인구직 사이트로 다양한 업직종 채용정보 찾는 요령
인천벼룩시장 구인구직 실시간 채용정보 찾는 방법
안산교차로 구인구직 신문 홈페이지 안내
```

라이프인포에서 146편을 비공개한 유형과 같다 — 확인 불가한 지역 채용
정보가 글의 핵심이라 AI 가 지어낼 수밖에 없다. 재고 42건이 아깝지만
승인용 블로그에 넣을 내용이 아니다.

## 적용할 설정

승인 준비를 마친 슈마즈·레시피노트·인포노트와 같은 조합이다.

| 대상 | 항목 | 값 |
|---|---|---|
| 카테고리 | 활성 | 자격증 · 직업 정보 · 취업 정보 (나머지 21개 비활성) |
| 프롬프트 모듈 189 | adsense_approval_preset | `adsense-approval` |
| | niche_enabled | true |
| | info_gain_enabled | true |
| | aeo_enabled | true |
| | adsense_auto | true |
| | exclude_sibling_titles | **true** |
| 성장 프로파일 190 | selectedPreset | `adsense` |
| | 생성·발행 | 1일 1편 |
| | 재발행 | **끔** (지금 4회/일) |

`exclude_sibling_titles` 만 기존 승인 블로그(false)와 다르게 true 로 둔다.
`worldin4master.blogspot.com` 은 blogspot 이 공용 접미사로 처리돼 형제가
없으므로 지금은 동작 차이가 없고, 나중에 블로그가 붙어도 중복을 막는다.

카테고리는 **삭제가 아니라 비활성**이다. `is_active=false` 는 재고 조회와
목록 API 모두가 걸러내고, 되돌리기도 한 줄이면 된다.

## 남는 문제 — 이번 작업으로 해결되지 않음

### 1. 재고가 4주치뿐

28건, 1일 1편이면 28일. 승인 신청에 필요한 20~30편은 되지만 그 뒤가
없다. **최근 30일 유입이 0건**이라 저절로 차지 않는다.

수집 모듈이 취업/자격증을 채우도록 조정해야 한다. 지금 수집은
생활 정보(87) · 음식/레시피(81) · 금융/대출(75) 로 쏠려 있다.

### 2. 수집이 반려 유형을 키우고 있다

유입 상위가 **매장·시설 정보(43)** 와 **고객센터·연락처(22)** 다.
품질 게이트가 경고로 잡는 바로 그 유형이고, 라이프인포에서 걷어낸
유형이다. 수집 단계에서 걸러야 생성·발행 단계의 부담이 준다.

### 3. 기존 153편

승인 심사는 사이트 전체를 본다. 지금 발행된 글에는 「티월드 고객센터
전화번호」, 「현대 HCN 고객센터 전화번호와 수리 방법」 같은 것이 섞여
있다. 카테고리를 좁혀도 이미 올라간 글은 그대로다.

정리 기능(`데이터 관리 → 정식제목`)으로 니치 밖 글을 비공개하는 것을
권한다. 다만 **몇 편을 남길지는 사용자 판단**이라 여기서 실행하지 않았다.

### 4. 블로그 이름과 니치가 어긋난다

「월드인포마스터」는 취업 정보를 다루는 사이트로 읽히지 않는다.
심사자가 사이트를 열었을 때 이름·설명·내용이 따로 노는 것은 불리하다.
Blogger 쪽에서 제목·설명을 니치에 맞게 바꾸는 것을 권한다(앱 밖 작업).
