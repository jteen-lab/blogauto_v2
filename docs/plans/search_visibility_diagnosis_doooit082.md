# doooit082 계열 검색 노출 실패 진단

## 1. 실측 결과

|---|---|---|---|---|
| 인생꿀팁 | 103 | **0** | 70 | 102 |
| 굿팁꿀팁 | 104 | **0** | 0(미확인) | 104 |
| 꿀팁대백과사전 | 102 | **0** | 0(미확인) | 102 |

굿팁꿀팁·꿀팁대백과사전은 GSC 속성이 없어 사유 확인 자체가 안 된다.

구글이 보고한 사유:

| 사유 | 인생꿀팁 | 잡학다식 |
|---|---|---|
| 발견됨 – 현재 색인이 생성되지 않음 | 62 | 43 |

**결정적 지표**: 색인 상세의 `lastCrawlTime` 이 **비어 있다**.
구글이 URL을 알면서도 **한 번도 가져가지 않았다**.

각 사이트의 최신 글 제목을 네이버 웹문서에서 그대로 검색한 결과:

| 꿀팁대백과사전 | **0건** |
| 잡학다식 | **0건** |

원장 기준 네이버 노출도 전 블로그 0건이다.

## 2. 기술 설정은 정상이다

원인을 기술 쪽에서 찾을 수 없다. 전부 확인했다.

| 항목 | 결과 |
|---|---|
| robots.txt | `Disallow:` 비어 있음(전체 허용) + 사이트맵 선언 |
| meta robots | `index, follow, max-image-preview:large` |
| canonical | 자기 URL로 정상 |
| Googlebot UA 응답 | HTTP 200, 135\~145KB 정상 반환 |
| 사이트맵 등록 | 4개 모두 present |
| 네이버 소유확인 | 3개 있음, **굿팁꿀팁만 없음** |

즉 **막혀서 못 오는 게 아니라, 올 이유가 없다고 판단된 상태**다.

## 3. 원인

### 3-1. 크롤 수요가 0에 가깝다 (핵심)

구글 John Mueller, 2026-07-16 Search Off the Record:

> 시스템이 사이트 품질을 심각하게 우려하면 **크롤링과 색인을 둘 다 줄인다.**
> 이것이 대규모의 "crawled not indexed" · "discovered not indexed" 로 나타난다.

지금 상태가 정확히 그 모습이다. `lastCrawlTime` 이 비어 있는 것이 증거다.

### 3-2. 발행 속도

| 블로그 | 전체 글 | 하루 평균 | 최대 |
|---|---|---|---|
| 인생꿀팁 | 1,049 | **12.5개** | 13개 |
| 굿팁꿀팁 | 456 | 5.9개 | 7개 |
| 꿀팁대백과사전 | 502 | 5.9개 | 7개 |
| 잡학다식 | 315 | 5.9개 | 8개 |

네 사이트 합쳐 **하루 30개**가 같은 소유자 아래에서 나온다.
검색 결과가 지적하는 "too many new URLs too quickly" 에 해당한다.

### 3-3. 네 사이트가 같은 주제 풀을 공유한다

전체 2,322개 제목을 대조했다.

- **105종의 제목이 두 개 이상 사이트에 중복 게재**
- 「자리톡 월세환급 비용 정리」는 **6번**, 「소고기 미역국 레시피」는 4번

다만 본문 유사도는 12.9% 로 **복사가 아니라 같은 제목으로 각각 AI 생성**한 것이다.
복사가 아니므로 "중복 콘텐츠 페널티" 는 아니지만, 구글 관점에서는 한 주체가
같은 주제를 여러 사이트에서 대량 생산하는 모습으로 읽힌다.

주제 구성도 네 사이트가 사실상 같다 — 고객센터 · 효능 · 재테크 · 여행 · 건강이
전부 섞인 잡탕이라 사이트마다 무엇을 다루는 곳인지 구분되지 않는다.

### 3-4. 콘텐츠 유형이 라이프인포에서 걷어낸 것과 같다

- 「티월드 고객센터 전화번호 안내」 「쏘카 고객센터 번호는 어디서 찾을까」
- 「롯데손해보험 고객센터 전화와 운영시간」 「현대 HCN 고객센터 전화번호」
- 「코스트코 상품권 카드와 현금 없이 쇼핑하는 법」

라이프인포에서 146개를 비공개 처리한 바로 그 유형이다.
확인 가능한 사실이 글의 핵심인데 그 값을 AI가 지어내는 구조다.

### 3-5. 본문이 얇다 (잡학다식)

| 블로그 | 본문 중앙값 | 최근 30개 중 2,000자 미만 |
|---|---|---|
| 인생꿀팁 | 2,362자 | 5개 |
| 잡학다식 | **1,588자** | **25개** |

## 4. 우리 앱이 만든 문제 — 고칠 수 있다

### 4-1. 제목이 두 번 출력된다

```html
<h1 class="entry-title">홈트 근력운동 효과적인 5가지 방법</h1>
<h2 id="홈트-근력운동...">홈트 근력운동 효과적인 5가지 방법</h2>
```

워드프레스 테마가 제목을 `<h1>` 으로 출력하는데, 우리 프롬프트가
`STEP 1 ▸ H1(#) 타이틀` 을 요구해 본문에도 같은 제목이 들어간다.
독자에게는 같은 문장이 두 번 보이고, 검색엔진에는 문서 구조가 어긋난 것으로 보인다.

### 4-2. 도입부에 관련 없는 링크가 5개 박힌다

```
홈트레이닝은 … 5가지 방법을 소개하겠습니다.
  레몬디톡스 효과적인 활용법 5가지
  일본여행 환전 꿀팁 5가지 총정리
  직장인을 위한 건강보험료 계산법 5가지
  담금주추천 초보자가 알아야 할 5가지
  리즈다이어트 성공을 위한 5가지 비법
1. 올바른 자세와 기술 익히기 …
```

모듈 설정이 `intro_count: 5`, `conclusion_count: 5` 라 글마다 내부링크가 10개
들어간다. 홈트 글 도입부에 레몬디톡스·일본여행 환전 링크가 붙는다.
주제와 무관한 링크 뭉치는 독자에게도 검색엔진에도 나쁜 신호다.

## 5. 애드센스는 승인됐는데 왜 검색은 0인가

두 심사는 기준이 다르다.

| | 애드센스 | 검색 색인 |
|---|---|---|
| 보는 것 | 정책 위반 여부, 필수 페이지, 광고 게재 적합성 | 이 문서를 검색 결과에 넣을 가치가 있는가 |
| 판정 단위 | 사이트 | **URL 하나하나** |
| 통과 후 | 유지됨 | 매 크롤마다 재평가 |

애드센스 승인은 "광고를 붙여도 되는 사이트" 라는 뜻이지 "검색에 노출할 만한
문서" 라는 뜻이 아니다. 승인 상태와 색인 상태가 따로 노는 것이 정상이다.

## 6. 해야 할 일

### 즉시 (우리가 할 수 있는 것)

| 순위 | 조치 | 근거 |
|---|---|---|
| 1 | **발행 중단 또는 대폭 감속** | 크롤 수요가 죽은 상태에서 계속 찍어내면 신호가 더 나빠진다 |
| 2 | **저품질 글 정리** — 고객센터·상품권류 비공개 또는 410 | 라이프인포와 같은 기준 |
| 3 | **H1 중복 제거** | 프롬프트에서 H1 요구를 빼거나 발행 시 첫 제목 제거 |
| 4 | **내부링크 5+5 → 2+2 이하** | 주제 무관 링크 뭉치 제거 |
| 5 | **사이트별 니치 분리** | 네 사이트가 같은 주제 풀을 쓰지 않게 |
| 6 | 굿팁꿀팁 GSC 속성 등록 + 네이버 소유확인 | 지금은 측정조차 안 된다 |

### 이후 (사용자 판단)

- 남길 글을 골라 **사람 손으로 보강**(실제 확인한 정보·출처·경험 추가)
- 색인 회복은 **수 주\~수 개월**. 구글은 회복 시점을 보장하지 않는다.
- 네이버는 서치어드바이저에서 **수집 요청**(하루 50개 수동)을 병행

### 하지 말아야 할 것

- 같은 속도로 계속 발행하며 색인을 기다리는 것
- 사이트를 더 늘리는 것 — 지금 문제는 사이트 수가 아니라 사이트당 품질이다

## 7. 정직하게 덧붙임

색인 실패의 원인을 **하나로 특정할 수는 없다.** 구글은 사유를
"발견됨 – 색인 생성 안 됨" 이상으로 알려주지 않는다.

다만 위 지표들(크롤 0회 · 하루 30개 발행 · 105종 주제 중복 · 지어낸 사실 기반
콘텐츠 · 얇은 본문)이 모두 같은 방향을 가리키고, 그 방향이 구글이 공개적으로
말한 "품질 우려 시 크롤링·색인 축소" 와 일치한다.

수동 조치(manual action) 여부는 **GSC 보안 및 수동 조치 페이지에서 사용자가
직접 확인**해야 한다. API로는 알 수 없다. 수동 조치가 걸려 있다면 재검토
요청이 필요하고, 없다면 알고리즘 평가가 회복될 때까지 품질 개선 후 대기다.
