## 1. 개요

### 1.1 목적
키워드와 제목을 자동으로 수집하여 블로그 콘텐츠 생성에 활용할 수 있는 데이터셋을 구축합니다.

### 1.2 핵심 기능
- **키워드 수집**: 네이버/구글에서 키워드 및 연관검색어 수집
- **제목 수집**: 키워드 기반 포스트 제목 수집
- **자동 분류**: 카테고리 자동 분류 및 필터링
- **데이터 관리**: 수집된 데이터의 CRUD 및 일괄 관리

## 2. 기능 요구사항

### 2.1 키워드 수집
| 기능 | 설명 | 우선순위 |
|------|------|:--------:|
| 검색 API 연동 | 네이버/구글 검색 API를 통한 키워드 수집 | 높음 |
| 연관키워드 확장 | 수집된 키워드의 연관검색어 자동 수집 | 높음 |
| 제목에서 키워드 추출 | 수집된 제목에서 키워드 추출하여 데이터셋 확장 | 중간 |
| 검색량/경쟁도 수집 | 키워드별 검색량, 경쟁도 지표 수집 | 높음 |
| 난이도(KD) 점수 | 상위 노출 경쟁 강도 분석 | 중간 |
| 검색 의도 분류 | 정보형/상업형/거래형 자동 분류 | 낮음 |
| 트렌드 분석 | 시계열 검색량 변화 추적 | 중간 |

### 2.2 제목 수집

## 3. 아키텍처

### 3.1 시스템 구조도
```
수집 모듈:
  키워드 수집 → 키워드 데이터셋 ↔ 연관키워드 확장
                    ↓
               제목 수집 → 임시제목 DB
                    ↑
  RSS 구독 ─────────┘
  뉴스레터 파서 ────┘

처리 엔진:
  임시제목 DB → 필터링 엔진 → 카테고리 분류 → 품질 평가 → 정식제목 DB

API 관리:
  API 계정 풀 → 사용량 모니터 → 한도 도달 시 계정 자동 전환
```

## 4. 데이터 모델

### 4.1 키워드 테이블 (keywords)
| 컬럼명 | 타입 | 설명 |
|--------|------|------|
| id | INTEGER | PK |
| keyword | VARCHAR(200) | 키워드 |
| search_volume | INTEGER | 월간 검색량 |
| competition | FLOAT | 경쟁도 (0-100) |
| difficulty | FLOAT | 난이도 (0-100) |
| intent | VARCHAR(20) | 검색 의도 |
| trend | VARCHAR(20) | 트렌드 방향 |
| source | VARCHAR(50) | 수집 소스 |
| is_active | BOOLEAN | 활성 상태 |
| created_at | DATETIME | 생성일시 |

### 4.2 제목 테이블 (titles)
| 컬럼명 | 타입 | 설명 |
|--------|------|------|
| id | INTEGER | PK |
| title | VARCHAR(500) | 제목 |
| category_id | INTEGER | FK → categories |
| source_url | VARCHAR(1000) | 원본 URL |
| source_type | VARCHAR(50) | 소스 유형 |
| status | VARCHAR(20) | 상태 (temp/official) |
| quality_score | FLOAT | 품질 점수 |
| note | TEXT | 비고 |
| is_active | BOOLEAN | 활성 상태 |
| created_at | DATETIME | 생성일시 |

### 4.3 카테고리 테이블 (categories)
| 컬럼명 | 타입 | 설명 |
|--------|------|------|
| id | INTEGER | PK |
| name | VARCHAR(100) | 카테고리명 |
| parent_id | INTEGER | FK (상위 카테고리) |
| keywords | TEXT | 분류 키워드 (JSON) |
| priority | INTEGER | 우선순위 |
| is_active | BOOLEAN | 활성 상태 |

### 4.4 필터 테이블 (filters)
| 컬럼명 | 타입 | 설명 |
|--------|------|------|
| id | INTEGER | PK |
| filter_type | VARCHAR(50) | 필터 유형 |
| filter_value | TEXT | 필터 값 |
| is_system | BOOLEAN | 시스템 기본값 여부 |
| is_active | BOOLEAN | 활성 상태 |

### 4.5 API 계정 테이블 (api_accounts)
| 컬럼명 | 타입 | 설명 |
|--------|------|------|
| id | INTEGER | PK |
| provider | VARCHAR(50) | 제공자 |
| account_name | VARCHAR(100) | 계정 식별명 |
| api_key | TEXT | API 키 (암호화) |
| daily_limit | INTEGER | 일일 한도 |
| used_today | INTEGER | 오늘 사용량 |
| is_active | BOOLEAN | 활성 상태 |

### 4.6 수집 설정 테이블 (collection_settings)
| 컬럼명 | 타입 | 설명 |
|--------|------|------|
| id | INTEGER | PK |
| setting_key | VARCHAR(100) | 설정 키 |
| setting_value | TEXT | 설정 값 |
| description | TEXT | 설명 |

## 6. 카테고리 분류 시스템

### 6.1 계층 구조
```
대분류 > 중분류 > 소분류

예시:
├── 건강/의학
│   ├── 비만 > 다이어트
│   └── 운동 > 홈트레이닝
├── IT/기술
│   └── 프로그래밍 > Python
└── 여행
    └── 국내여행 > 제주도
```

### 6.2 분류 로직
1. 각 카테고리의 키워드와 제목 매칭 확인
2. 매칭된 키워드 중 우선순위가 높은 카테고리 선택
3. 우선순위 동일하면 제목 앞쪽 위치 키워드의 카테고리 선택
4. 매칭 없으면 "미분류"

## 7. 데이터 관리 UI

### 7.1 탭 구조
| 탭 | 설명 |
|----|------|
| 키워드 | 키워드 데이터셋 관리 |
| 임시제목 | 수집된 임시 제목 관리 |
| 정식제목 | 검증된 정식 제목 관리 |
| 소스관리 | API 계정, RSS 피드 관리 |
| 필터설정 | 필터 규칙 설정 |

### 7.2 키워드 테이블 컬럼
```
번호 | 키워드 | 검색량 | 경쟁도 | 난이도 | 의도 | 트렌드 | 소스 | 수집일 | 액션
```

### 7.3 임시제목 테이블 컬럼
```
번호 | 제목 | 카테고리 | 작성일 | 비고 | 액션
```
- 카테고리: 분류된 경우 `대분류 > 중분류`, 미분류 시 `미분류`

### 7.4 공통 UI 기능
- 대시보드: 수집 현황, API 사용량, 최근 활동 요약
- 일괄 작업: 선택 항목 일괄 삭제/카테고리 변경
- 검색/필터: 키워드/날짜/카테고리별 빠른 검색
- 내보내기: CSV/Excel 다운로드
- 대량 업로드: CSV/Excel 파일 일괄 등록
