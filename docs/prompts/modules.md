## 완성 예시 1 — 모듈 1 (S1 / AI · IT / 전문가·중급·P1·수치)

```
제목: {title}
카테고리: {category}
키워드: {keywords}

────────────────────────────────────────
✦ 글쓰기 페르소나 — 전문가 설명체
────────────────────────────────────────
- "~합니다", "~됩니다", "~로 나타납니다" 격식 종결
- 전문 용어는 그대로 사용, 필요시 한 줄 보충
- 수치·근거·비교 적극 활용, 감정 표현·감탄사 최소화
- 평가는 비교 우위 형식으로 표현 ("A 가 B 대비 ~ 우위")

────────────────────────────────────────
✦ 독자 수준 — 중급자
────────────────────────────────────────
- 기본 개념은 이미 알고 있음을 가정
- 용어 풀이 생략, 비교·장단점·실용 정보 위주
- 표/목록은 다열 비교 가능한 형태
- 정보 밀도 보통, 깊이 있게 한 단계 더 파고듦

────────────────────────────────────────
✦ 글쓰기 기본 원칙
────────────────────────────────────────
- 마크다운 작성
- 제목(#~######) 앞 번호 금지, 특수문자 금지
- "STEP 1", "단계 1" 같은 메타 텍스트와 구분선(─, ---) 출력 금지
- STEP 1~4 멈추지 않고 한 번에 완성
- 해시태그 금지

────────────────────────────────────────
✦ 구조 — 패턴 P1 (정보·정리형)
────────────────────────────────────────
- A: 개념·배경 정리
- B: 대표 옵션·항목 비교표 ← 표 반드시 포함
- C: 활용 팁 목록 ← 번호/불릿 목록 반드시 포함
- D: 심화·자주 헷갈리는 부분
- E: 비용·수치·항목 정리표 ← 표 반드시 포함
- F: 주의사항 목록 ← 번호/불릿 목록 반드시 포함

────────────────────────────────────────
✦ 시작 톤 — 현황·수치·문제의식
────────────────────────────────────────
- 시장 동향·통계·수치로 시작 (예: "최근 N년간 X 가 Y % 증가")
- 또는 핵심 문제·딜레마 한 문장으로 화두 제시
- 격식 있는 도입, 감정 표현 배제

────────────────────────────────────────
✦ 구조 약속
────────────────────────────────────────
STEP 1 ▸ H1(#) 타이틀 + 도입 200자+ (위 시작톤 적용, "안녕하세요" 금지)
STEP 2 ▸ ## 섹션 A·B·C 각 250자+ (B 표 필수, C 목록 필수)
STEP 3 ▸ ## 섹션 D·E·F 각 250자+ (E 표 필수, F 목록 필수)
STEP 4 ▸ ## 마치며 200자+ (담백한 정리 + 댓글·경험 공유 유도)
```

## 나머지 13개 만드는 방법

1. 위 카탈로그에서 만들 모듈 행 선택 (예: 모듈 5 = S2 / 건강·의학)
2. 카탈로그의 페르소나/독자수준/섹션패턴/시작톤 코드 확인 (모듈 5: P-선생님 / R-입문 / P2 / T-학습)
3. **완성 예시 1 또는 2 를 통째로 복사**
4. 4개 블록(페르소나·독자수준·섹션패턴·시작톤) 자리에 `style_blocks.md` 에서 해당 코드 블록을 복붙
5. 나머지 (기본 원칙·구조 약속) 는 그대로 유지
6. BlogAuto 모듈 만들기 → settings 의 카테고리 필터에 해당 카테고리 선택 → user_prompt_template 자리에 위 완성 프롬프트 붙여넣기

## V2 변주 만드는 법 (같은 카테고리 다른 모듈)

같은 카테고리에 모듈을 추가로 만들 때 차별화 포인트:

| 변경 강도 | 무엇을 바꾸는가 | 효과 |
|---|---|---|
| **약** | 시작 톤만 변경 (예: T-수치 → T-정의) | 도입부 인상 다름 |
| **중** | 섹션 패턴 변경 (예: P1 → P4) | 글 구조·정보 흐름 다름 |
| **강** | 페르소나 변경 (예: 전문가 → 분석가) | 어투 자체 다름 |
| **최강** | 클러스터 자체 이동 (예: S1 → S5) | 전혀 다른 글 |

같은 클러스터 안에서 **중~강** 정도 변경이 균형 좋음. 너무 다르면 카테고리에 안 맞고, 너무 같으면 결과물이 비슷함.
