## 5개 스타일 클러스터

| 클러스터 | 성격 | 권장 페르소나 | 권장 독자수준 | 권장 섹션패턴 |
|---|---|---|---|---|
| **S1** 전문·분석형 | 정보 농도 높음, 근거·수치 중심 | 전문가 설명체 / 데이터 분석가 | 중급 / 결정단계 | P1 정보·정리 / P4 분석·결정 |
| **S2** 교육·안내형 | 단계별 안내, 입문자 친화 | 선생님 강의체 | 입문 | P2 교육·안내 / P3 가이드 |
| **S3** 생활·공감형 | 친근한 일상, 공감 위주 | 친구 구어체 | 입문 | P5 경험·공감 / P2 교육·안내 |
| **S4** 감성·경험형 | 1인칭 회고, 장면 묘사 | 에세이 서술체 | 입문 / 중급 | P5 경험·공감 / P3 가이드 |
| **S5** 실용·정보형 | 담담한 팩트, 비교·정리 | 중립 정보체 | 중급 | P1 정보·정리 / P4 분석·결정 |

## 카테고리 → 클러스터 매핑

1차 카테고리 기준. 2차 카테고리가 강한 성격을 가지면 우선 적용.

### S1 전문·분석형
- AI · 인공지능 · 머신러닝
- IT · 개발 · 프로그래밍 · 소프트웨어
- 과학 · 기술
- 금융 · 투자 · 주식 · 펀드
- 부동산 · 재테크
- 경제 · 시장
- 법률 · 세무 · 회계

### S2 교육·안내형
- 건강 · 의학 · 영양
- 육아 · 교육
- 자기계발 · 공부법
- 자격증 · 시험
- 어학 · 외국어

### S3 생활·공감형
- 라이프스타일 · 일상
- 인테리어 · 홈가전
- 반려동물
- 패션 · 뷰티 · 코디
- 쇼핑 · 직구
- 결혼 · 연애

### S4 감성·경험형
- 여행 · 국내·해외여행
- 맛집 · 카페
- 음식 · 요리
- 문화 · 예술 · 공연
- 영화 · 드라마
- 책 · 독서

### S5 실용·정보형
- 자동차 · 캠핑카
- 가전 · 제품 리뷰
- 앱 · 서비스 리뷰
- DIY · 만들기
- 취미 · 스포츠
- 사진 · 영상

## 매칭 규칙 (운영자 판단 기준)

1. **1차 카테고리 우선 매칭** — 위 표에서 1차가 해당하는 클러스터로 결정.
2. **2차 카테고리가 강하면 재배치** — 예: 1차 "라이프(S3)" + 2차 "재테크 일기" → S1로 옮길 수 있음.
3. **혼합 카테고리는 큰 비중 따라** — 예: "여행+사진" → 사진 비중이 작으면 S4, 사진이 주이면 S5.
4. **모호하면 S5(중립)로 시작** — 운영하면서 결과 보고 조정.

## 클러스터별 다버전 변주 예시

같은 클러스터 안에서 2~3개 모듈을 만들 때 차별화 포인트:

| 클러스터 | V1 (메인) | V2 (변주) | V3 (선택) |
|---|---|---|---|
| **S1** | 전문가 / 중급 / P1 | 분석가 / 결정 / P4 | 전문가 / 중급 / P3 |
| **S2** | 선생님 / 입문 / P2 | 선생님 / 입문 / P3 | 선생님 / 중급 / P2 |
| **S3** | 친구 / 입문 / P5 | 친구 / 입문 / P2 | 친구 / 입문 / P3 |
| **S4** | 에세이 / 중급 / P5 | 친구 / 입문 / P5 | 에세이 / 중급 / P3 |
| **S5** | 중립 / 중급 / P1 | 중립 / 중급 / P4 | 중립 / 중급 / P3 |

V2/V3는 같은 어투를 유지하되 섹션 패턴이나 독자 수준만 바꿔 결과물 다양성을 확보한다.
