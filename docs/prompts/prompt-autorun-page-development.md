## 🎯 핵심 개념 정리

### 상태 정의

| 상태 | 의미 | 표시 위치 |
|------|------|----------|
| **활성 (Active)** | 오토런에 추가됨, 스케줄에 따라 자동 동작 | 오토런 페이지 |
| **일시정지 (Paused)** | 오토런에 추가됨, 사용자가 수동으로 멈춤 | 오토런 페이지 |
| **오토런 미추가** | 오토런에 추가되지 않음 | 오토런 하단 시트에서 선택 가능 |

### 일시정지 동작 방식

```
[활성 상태] 🟢
  │
  ├── 스케줄 도래 → 동작 실행
  │
  └── [⏸ 일시정지 클릭]
        │
        ▼
[일시정지 상태] 🟡
  │
  ├── 스케줄 도래 → 건너뜀 (동작 안 함)
  │
  └── [▶ 재개 클릭]
        │
        ├── 지나간 스케줄은 무시
        └── 다음 스케줄부터 동작
```

### 플로우 관리 vs 오토런 관계

```
[플로우 관리 페이지]
├── 생성된 모든 플로우 표시 (오토런 추가 여부 무관)
├── 플로우 생성/수정/삭제
└── 플로우 설정 관리

[오토런 페이지]
├── 오토런에 추가된 플로우만 표시
├── 활성 / 일시정지 상태 관리
├── [+ 추가] 클릭 → 오토런 미추가 플로우 선택 가능
└── 동작 로그 확인
```

## 🗄️ 데이터베이스 변경

### flows 테이블 필드 추가

```python
# app/models/flow.py 수정
class Flow(Base):
    # ... 기존 필드
    
    # 오토런 관련 필드 추가
    is_in_autorun: bool = Column(Boolean, default=False)  # 오토런에 추가됨
    is_paused: bool = Column(Boolean, default=False)       # 일시정지 상태
    added_to_autorun_at: datetime = Column(DateTime, nullable=True)  # 오토런 추가 시간
```

### autorun_logs 테이블 (신규)

```python
# app/models/autorun_log.py (신규)
class AutorunLog(Base):
    __tablename__ = "autorun_logs"
    
    id: int = Column(Integer, primary_key=True)
    flow_id: int = Column(Integer, ForeignKey("flows.id"))
    log_type: str = Column(String(50))  # start, progress, success, fail, pause, resume
    message: str = Column(String(500))
    details: str = Column(Text, nullable=True)  # JSON 형태 상세 정보
    created_at: datetime = Column(DateTime, default=datetime.utcnow)
    
    flow = relationship("Flow", back_populates="autorun_logs")
```
