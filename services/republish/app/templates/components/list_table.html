{# 공용 목록 표 — 블로그·모듈·플로우·오토런이 같은 로직과 스타일을 쓴다. 화면마다 따로 만들면 동작이 갈라지고 고칠 곳이 네 배가 된다. 컴포넌트는 그리기만 하고, 무엇을 그릴지(열·배지·액션)는 화면이 Alpine 함수로 준다. 컴포넌트가 특정 화면의 필드를 알면 재사용이 안 된다. 데스크톱은 표, 모바일은 2줄 목록. **같은 배열을 그린다** — 모바일 전용 데이터를 따로 만들면 정렬·필터 결과가 갈린다. 액션은 **화면이 마크업으로 준다**(`actions_include`). 컴포넌트가 액션을 대신 그리게 했더니 하단시트가 열리지 않았다. 카드에서 검증된 직접 호출 (`@click="openEditSheet(blog)"`)을 그대로 쓰는 것이 안전하다. 필요한 변수 rows_expr : 행 배열 Alpine 식 (예: "sortedBlogs('wordpress')") row_key : 행 변수명 (예: "blog") empty_text: 비었을 때 문구 actions_include: 행 액션 마크업 템플릿 경로 max_height: 표 본문 최대 높이 (예: "26rem"). 없으면 제한 없음 화면이 제공할 Alpine 함수 listColumns() [{key,label,align,width,strong,link,sortable}] listCell(row, key) 셀 텍스트 listBadges(row) [{label,cls,dot,pulse,tip}] listSort(key) / listSortIcon(key) 정렬 토글·표시 listTitle(row)/listSub(row) 모바일 1·2줄 순서도: docs/flowcharts/list_table_component.md #}
