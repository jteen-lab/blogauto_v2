블로그 검색 및 뉴스 제목 수집에 사용됩니다

네이버 검색 API는 네이버 개발자센터에서 발급받을 수 있습니다. (검색 > 블로그 검색 API 사용 신청)

구글 트렌드 연동됨

실시간 인기 검색어 및 연관 검색어 수집에 사용됩니다 (인증 불필요)

실시간 인기 검색어 (샘플)

구글 트렌드는 공개 API로 별도 인증 없이 사용 가능합니다. 단, 과도한 요청 시 일시적으로 제한될 수 있습니다.

네이버 데이터랩 연동됨

네이버 데이터랩 API는 네이버 개발자센터에서 발급받을 수 있습니다. (데이터랩 > 검색어트렌드 API 사용 신청)

구글 키워드 플래너 연동됨

키워드 아이디어 및 검색량 조회에 사용됩니다 (Google Ads 계정 필요)

참고: Google Keyword Planner API는 활성 Google Ads 계정이 필요합니다. Google Ads API 시작하기에서 자세한 설정 방법을 확인하세요.

Celery 워커 설정

워커를 활성화하면 작업이 별도 프로세스에서 비동기 실행됩니다

AI Rate Limit 설정

AI 서비스별 분당 최대 요청 수(RPM)와 토큰 수(TPM)

유사도 매칭 설정

정식제목 그룹핑(수동 승격·데이터 모듈 공통). 임계값 근처의 애매한 점수만 AI가 '같은 주제?'를 판정.
