# CPA 제휴 마케팅 — 외부 유입 전략 조사

> 작성 2026-09-10 | 목적: "글을 자동 생성한다"가 아니라 **"외부 유입으로 승인 DB를 만든다"**로 전략 축을 다시 세우기 위한 사전 조사

---

## 1. 돈이 생기는 지점부터 다시 본다

애드릭스는 CPC·CPA·CPS를 모두 다루고 **1포인트 = 1원**으로 환전된다.
우리가 등록한 안과 오퍼는 CPA 중에서도 **상담 신청 DB**형이다.

```
접수 항목    이름 · 핸드폰번호 · 문의내용
미승인 조건  오류 · 결번 · 중복 · 미성년자 · 장기부재 · 상담거절
```

그래서 수익은 이렇게 결정된다.

```
수익 = 유입 × 상담신청 전환율 × 승인율 × 건당 단가
```

**애드센스와 결정적으로 다른 지점이 승인율이다.** 조회수는 한 푼도 되지 않고,
미승인 DB는 0원인 데다 광고주 신뢰까지 깎는다. 미성년자·장기부재·상담거절이
미승인 조건에 있다는 것은 **아무나 부르면 안 된다**는 뜻이다.

업계 단가 감각(2026 기준): 일반 CPA 캠페인 1건 5,000원 내외, 애드릭스는
1만~3만 포인트대까지 책정. 광고주 쪽 계산식은 `최대 계약단가 12만원 ×
문의→계약 전환율 10% = 허용 DB 단가 1.2만원` 식으로 잡힌다.

## 2. 애드센스와 무엇이 다른가

| | 애드센스 | CPA |
|---|---|---|
| 수익 단위 | 노출·클릭 | **승인된 DB만** |
| 필요한 트래픽 | 많을수록 좋다 | **맞는 사람만**. 틀린 유입은 마이너스 |
| 글의 목적 | 체류·정보 | 행동(상담 신청) |
| 유입 성격 | 오가닉 검색 | 외부 유입 포함 능동적 송출 |
| 규제 층 | 애드센스 정책 1층 | 플랫폼 + 업종법 + 광고주 규칙 **3층** |
| 실패 비용 | 낮음 | 미승인 DB·계정 정지·**형사처벌**(의료) |

애드센스 전략(양 → 오가닉 → 노출)을 그대로 CPA에 옮기면 **모든 층에서 동시에
걸린다.** 대량 자동 발행은 애드센스에서는 scaled content abuse 하나였지만,
CPA에서는 플랫폼 스팸 + 광고주 규칙 위반 + 업종법 위반이 겹친다.

## 3. 외부 유입 경로 지도

### ① 검색 유입 — 네이버 블로그
- **방식**: 정보성 글 → 상담 페이지 → 랜딩
- **제재 지점**: 광고성 포스팅 비율이 전체의 30%를 넘으면 저품질 위험.
  복사 콘텐츠·300자 미만·금칙어·특정 업체명 반복이 스팸 판정 트리거로 보고됨.
  네이버는 2026년 7월 AI탭 신뢰도를 이유로 광고 카페·광고글 단속을 강화 중.
- **우리 적용**: 가능하나 **의료 오퍼는 사전심의 대상**(§5 참조)

### ② 검색 유입 — 구글(티스토리·워드프레스)
- **방식**: 크롤링 → 인덱싱 → 랭킹. GSC·사이트맵·내부링크 기본기
- **제재 지점**: 링크 스팸 업데이트. 제휴 링크에 `rel="sponsored"` 미표기,
  얇은 중개(브릿지) 페이지는 걸러진다
- **우리 적용**: **자사 도메인이라 통제권이 가장 크다.** 우선순위 1순위 후보

### ③ 카페·커뮤니티
- **방식**: 관련 카페 게시판에 정보 글 + 링크
- **제재 지점**: 네이버 카페 운영원칙상 "영리 목적 광고 또는 특정 개인·단체
  홍보성 글"은 삭제·계정 차단 대상. 매크로·반복 광고글은 상시 모니터링.
  전자상거래법 위반으로 방통위·공정위 시정조치 사례도 있음
- **우리 적용**: 광고주가 후기성 내용을 금지해 카페의 주력 포맷(후기)을 못 쓴다.
  **효율 대비 위험이 가장 높은 채널**

### ④ SNS — 인스타그램·스레드·틱톡
- **방식**: 콘텐츠 + 프로필 링크
- **제재 지점**: 브랜디드 콘텐츠는 **파트너 태그로 협찬 표시 의무**.
  미표시·미해결 시 계정 기능 제한. 2026년 인스타는 수집·재업로드 계정에
  제휴 링크·상업 트래픽을 붙이는 행위를 정책으로 정리해 단속 중
- **우리 적용**: 안과 오퍼는 **심의받은 이미지 배너만** 허용 → 자유 제작 불가

### ⑤ 메신저·밴드 — 카카오 오픈채팅, 네이버 밴드
- **방식**: 주제형 방 운영 → 신뢰 축적 → 정보 제공
- **제재 지점**: 방 규칙·스팸 광고 방지가 운영 책임. 동의 없는 수신자에게
  광고를 보내면 정보통신망법 위반(개인정보 이용 동의 문제)
- **우리 적용**: 구축에 시간이 오래 걸려 단기 검증에는 부적합

### ⑥ 유료 트래픽 — 메타·구글·네이버 GFA·네이티브 애드
- **방식**: 소재 → 랜딩/상담 페이지. 전환 최적화 가능
- **제재 지점**: **2026년 Meta는 헬스케어 리드 생성을 정조준.** 의료기관·행동
  건강 클리닉의 리드폼 광고, 픽셀 전환 이벤트, 맞춤·유사 타겟이 심사 대상으로
  들어갔고 헬스케어 광고주의 73%가 최근 12개월 내 컴플라이언스 사유로 광고
  거부를 겪었다고 보고됨. 네이티브 애드는 승인 전 소재·랜딩 사전 심사
- **우리 적용**: 안과 오퍼는 **광고주가 포털 검색광고를 금지**했고, 유료 집행은
  비용 리스크가 커 검증 단계에서는 제외

### ⑦ 지식인·Q&A
- **방식**: 질문 답변에 정보 제공
- **제재 지점**: 상업적 답변·링크 반복은 제재 대상. 의료는 답변 자체가
  의료법 광고에 해당할 수 있음
- **우리 적용**: 자동화 부적합

## 4. "제재를 피하는 법"의 실제 내용

먼저 분명히 해 둘 것이 있다. **다계정·매크로·클로킹처럼 플랫폼 탐지를
우회하는 기법은 이 보고서에서 다루지 않는다.** 이유는 도덕이 아니라 계산이다.
우리 주력 오퍼가 의료라 걸리는 것이 계정 정지가 아니라 **형사처벌**이다.

```
금지 의료광고     최대 징역 1년 / 벌금 1천만원
환자 유인·알선    최대 징역 3년 / 벌금 3천만원
```

계정을 새로 파서 복구되는 종류의 위험이 아니다. 그래서 실무에서 "제재를
피한다"는 것은 **세 층의 규칙을 동시에 만족시킨다**는 뜻이 된다.

### 층 1 — 표시 의무 (공정위)

2024-12-01 시행 개정 「추천·보증 등에 관한 표시·광고 심사지침」:

- 대가성 문구를 **제목 또는 내용 첫 부분**에 표시 (기존의 "끝부분 게재" 불가)
- 현금·상품·상품권·적립 포인트·할인 혜택 모두 "경제적 대가"에 포함
- **"소정의 수수료를 지급받을 수 있음" 같은 조건부·불확정 표현 금지** —
  "지급받음", "받았음"으로 확정 표기

> 우리 시스템은 이미 `gate.py`의 `_check_notice`가 문구 존재 + 앞부분 400자
> 이내 위치를 차단 수준으로 검사한다. 이 부분만은 설계가 맞았다.

### 층 2 — 업종법 (의료법)

- **제56조**: 거짓·과장, 비교·최상급, 치료경험담, 부작용 누락, 비급여 할인 유인
- **제57조 사전심의**: 전년도 말 기준 직전 3개월 **일평균 이용자 10만 명 이상**
  인터넷 매체에서 의료광고를 하려면 **의무 사전심의**

### 층 3 — 플랫폼 정책 + 광고주 규칙

플랫폼별 요구는 §3에, 광고주 규칙은 오퍼 가이드라인에 있다. 이 둘은 서로
모순될 수 있다 — 광고주가 "SNS는 심의 배너만"이라 했는데 인스타는 협찬 태그를
요구하는 식이다. **모순은 자동으로 해소되지 않는다. 사람이 판단해야 한다.**

## 5. 안과 오퍼에 대입하면 — 남는 길이 거의 없다

| 채널 | 막는 주체 | 사유 |
|---|---|---|
| 네이버 검색광고(파워링크·파워컨텐츠·플레이스) | **광고주** | 심의받은 내용으로 본원이 단독 진행 중 |
| 인스타·페북·밴드·앱 광고 | **광고주** | 심의받은 이미지 배너만 사용 가능 |
| 카페·커뮤니티 후기 | **광고주 + 의료법** | 치료경험담 광고 불법 |
| 네이버 블로그 포스팅 | **의료법 제57조** | 일평균 10만 명 이상 매체 → 사전심의 대상 |
| 유튜브·틱톡 | **의료법 제57조** | 동일 |

여기서 가장 중요한 발견입니다.

> **사전심의 10만 명 기준은 우리 계정 규모가 아니라 플랫폼 규모다.**
> 방문자가 하루 10명인 블로그라도 네이버 블로그에 올리면 심의 대상이다.

심의 면제 여지는 **의료기관이 직접 운영하는 자사 도메인 홈페이지형**뿐인데,
우리는 의료기관이 아니라 제휴 마케터라 **면제 대상으로 보기 어렵다.**
(법률 확인이 필요한 항목으로 남긴다.)

**결론: 지금 상태로 안과 오퍼를 자동 대량 발행하는 것은 위험이 수익을 넘는다.**
글의 품질이나 규칙 추출 정확도의 문제가 아니라, 채널 자체가 막혀 있다.

## 6. 그래서 검증은 이렇게 설계한다

### 측정해야 할 다섯 숫자

```
노출 ─→ 클릭(랜딩 도달) ─→ 상담신청 ─→ 승인 ─→ 수익
      ①              ②            ③        ④
```

- ① 우리가 계측 가능 (미구현)
- ② **네트워크만 안다** → 서브아이디로 대사
- ③ 네트워크 리포트
- ④ 네트워크 리포트

### 이미 갖춘 것

| 모듈 | 하는 일 |
|---|---|
| `services/cpa/subid.py` | 랜딩 URL에 `o12-p345-b7` 형태 서브아이디 부착 |
| `services/cpa/consult_page.py` | 상담 페이지 생성. 900자 미만이면 "얇다" 경고 |
| `services/cpa/gate.py` | 대가성 문구·위치 차단 검사 |

`subid.py` 주석에 이미 정확한 문장이 있다 — *"CPA는 글 10편이 전부를 벌고
990편이 0원인 구조라, 어느 10편인지 모르면 다음 글을 어떻게 쓸지 알 수 없다."*

### 없는 것

1. **클릭 계측** — 우리 글에서 랜딩으로 나간 클릭 수를 우리가 모른다
2. **리포트 대사** — 네트워크 전환 데이터를 서브아이디로 우리 글에 붙이는 절차
3. **채널 기록** — 어느 채널에 뿌렸는지 데이터가 없다

### 최소 실험 단위

```
오퍼 1개 × 글 1편 × 채널 1개 × 서브아이디 1개
```

**판정 기준을 먼저 정하고 시작한다.** 예: 2주간 클릭 30 미만이면 채널 실패,
클릭 30 이상인데 상담 0이면 상담 페이지 실패, 상담은 있는데 승인 0이면
타겟팅 실패. 어느 단계가 실패했는지 구분되지 않으면 다음에 무엇을 고칠지 모른다.

## 7. 권고

1. **검증 오퍼를 바꾼다.** 안과(의료) 대신 **이사스토리(생활서비스)** 로.
   의료법 리스크가 없고 규칙이 27건으로 단순해 시스템 검증에 집중할 수 있다.
   의료 오퍼는 채널이 열린 뒤에 다시 붙인다.
2. **첫 글은 자동 생성하지 않는다.** 수작업 또는 반자동으로 1편.
   생성 품질과 유입 구조를 동시에 검증하면 실패 원인이 섞인다.
3. **클릭 계측을 먼저 만든다.** 이게 없으면 실험 결과를 읽을 수 없다.
   `/go/{offer}/{post}` 형태의 자체 리다이렉트 + 서브아이디 부착.
4. **규칙 추출 재작업은 그 다음이다.** 지금 추출이 부정확한 건 사실이지만,
   채널이 막혀 발행 자체가 안 되는 상태에서는 우선순위가 낮다.
