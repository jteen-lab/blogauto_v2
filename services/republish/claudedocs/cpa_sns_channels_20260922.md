## 2. 채널별 상세

### 2.1 X (구 트위터) — 부적합

- **수익화**: Creator Revenue Sharing 2026-09-07 종료 → Original Content Rewards(2026-09-08~). 자격: Premium 구독 + 검증 팔로워 500 + 90일 검증노출 50만. 지급 2주마다 최소 $30. **"자동화 수단으로 생성·게시된 콘텐츠" 명시 제외** → blogauto 자동 게시는 보상 대상 아님.
- **API**: 2026-02-06 신규 무료티어 폐지 → pay-per-use. 링크 포함 게시 $0.20/건. 일 40건 링크 게시 = 월 약 $240, 유입 0에서 선불.
- **링크 도달**: 2026-03부터 비프리미엄 외부링크 게시물 노출 거의 0. 프리미엄도 50~90% 손실. 우회(링크는 답글)는 자동 답글 금지에 걸림.
- **자동화 규칙**: 동일·실질 유사 게시물 금지(형제블로그 패턴 충돌), 봇 명시 필수, 리다이렉트 링크 금지.
- **한국 사용자층**: 팬덤·엔터 중심. 이사/대출/법률 즉시니즈와 결이 다름.
- 최소 실험이라면 프리미엄 계정 1개·수작업·링크는 답글·하루 1~3건. 당근 실험보다 후순위.

### 2.2 스레드 — 조건부 실험

- **API**: 무료. 프로필당 24h 게시 250·답글 1,000·삭제 100. 완전 자동 게시 공식 지원 + 답글 API → "본문 게시 → 첫 댓글 링크 → 고정" 자동화 가능. 개인 자동화는 개발모드로 App Review 없이 가능. 장기 토큰 60일 갱신.
- **링크 도달**: 본문 링크는 노출 감소(통설 10개 중 1~2개만). 표준 운영: 본문 무링크 → 30분 내 반응 확인 → 첫 댓글 링크 고정. 알고리즘 5신호(인게이지먼트·답글 관심·팔로우 확률·프로필 클릭·스크롤 패스). **첫 1시간 답글 응대는 사람 몫**(대화 깊이 5배 가중치).
- **제재 신호**: 해시태그 5개↑ 스팸, 동일 포맷 반복 감점(템플릿 대량생성과 충돌), 비원본 반복 시 계정 전체 도달 축소, 제한이 조용히 걸림(2주간 모르고 운영한 국내 사례).
- **계정 구조**: 인스타 계정 종속 → 12블로그 = 인스타 12개 필요, 다계정 생성은 Meta 본인확인·연계 제재 리스크. 계정 1~2개로 시작.
- **한국**: 스레드 주요 시장, 정보성·부업·자기계발 활발.
- **권장 실험**: 스레드 계정 1개(니치: 이사/생활서비스), blogauto가 글 요약→후킹 본문 LLM 생성(글마다 다르게)→API 게시→첫 댓글 링크 자동→서브아이디 추적, 하루 1~3건, 2주 후 클릭/승인 판정.

### 2.3 인스타그램 — 부적합(존재증빙만)

- **API**: Graph API 무료. 프로페셔널 계정 + 페이스북 페이지 연결 필수. 컨테이너→게시 2단계. 한도 100건/24h(일부 문서 50, `GET /{ig-user-id}/content_publishing_limit`로 확인). 프로덕션은 앱 리뷰 2~4주.
- **링크**: 클릭 가능한 곳 = 바이오(5개)·스토리 링크스티커·쇼핑 상품태그·DM·광고 CTA. 피드/릴스 캡션·댓글 URL은 클릭 불가. **스토리 링크스티커는 API 미지원**(모든 인터랙티브 요소, 서드파티 툴 전부 동일). → 자동화로 실을 수 있는 링크는 바이오뿐(2단계 이탈, 오퍼별 분기 불가). 쇼핑 태그는 자사 카탈로그 한정이라 상담형 CPA 무관.
- **리스크**: 2026-05-28 무결성 정책 개정(스트라이크 24h~30일). CEO 공개 경고 감점 목록: 재업로드·캡션만 변경·로고 제거·**카드뉴스 캡처 재활용·단순 요약** — 블로그 글→이미지 변환 반복이 정확히 해당. 비원본 시 계정 전체 도달 축소.
- **활용**: 스레드 실험 시 동일 Meta 계정 실존 증빙용 수동 소량 게시만. 별도 예산 없음.

### 2.4 페이스북 — 페이지만 조건부

- **개인 프로필**: ToS 3.2 자동화 금지. 네이티브 예약 2024초 삭제. 프로페셔널 모드도 API 게시 없음. 확장·자동클릭 봇은 영구 정지 사유, 봇 제거 후에도 제재 지속 사례.
- **그룹**: Groups API 2024-04-22 폐지(`publish_to_groups` 제거). Buffer·Hootsuite 포함 전부 불가. 수동 또는 세션 내 확장만. 고빈도 게시 자체가 스팸 위반이라 수동 홍보도 배제.
- **페이지**: Pages API 무료. 앱 생성 + 페이지 액세스 토큰. 파트너 API 경유는 정식 허용.
  - 외부 링크 게시물 도달 최하위(10년째, 2026 강화).
  - **본문 링크 월 2건 제한**: 비Meta Verified 페이지·프로페셔널 프로필. 2025-12-16 제한 테스트 → 2026 파급 롤아웃, 전면 출시 발표 없음. 해제 = Meta Verified $14.99~$500/월.
  - **예외**: 댓글 링크 무제한, 제휴 링크도 댓글이면 OK, Meta 내부 링크 예외. → 스레드와 같은 "본문 네이티브 + 첫 댓글 링크" 구조 성립. Pages API로 자기 게시물 댓글 가능.
  - 2026-03 "Rewarding Original Creators": 비원본 반복 시 수익화 차단 + 도달 축소, 중복 감지 시 사본 도달 강제 축소.
  - 페이지는 관리자 개인계정 종속 → 연쇄 리스크.
- **수익화**: Content Monetization 한국 국가·언어 적격, 팔로워 최소치 미공표·초대제. 자동생성 콘텐츠는 원본성 정책상 대상 아님.
- **한국**: 사용자 감소, 40~50대 주력 — CPA 오퍼 타깃과는 오히려 일치.
- **판정**: 스레드 파이프라인에 동반 시 추가 비용 낮음. 단독 선행 이유 없음. Meta Verified는 실험 성과 전 불필요(링크 제한 해제일 뿐 도달 개선 아님).

## 3. 홍보 방식 효율 순위 (반자동 허용 전제, 2026-09-22 웹 재조사)

`cpa_revenue_models_20260910.md`의 "유료 트래픽 아비트리지 우선" 결론이 재조사에서도 유지됨.

| 순위 | 방식 | 자동화 | 비용 | 속도 | 근거 |
|---|---|---|---|---|---|
| **1** | **당근 리드폼/랜딩 광고** | 반자동 | CPC 300~600원 | 즉시 | DB 실전환율 최고, 교육 업종 CPA −64% |
| 2 | 메타 리드광고(인스턴트폼) | 반자동 | 업종별 | 즉시 | 리드 많으나 즉흥 신청·품질 편차 |
| 3 | 구글 검색광고 | 반자동 | 고CPC | 즉시 | 의도 명확·상담연결률 높음. 마진가드 전제 |
| 4 | 자사 도메인 SEO | 완전자동 | 0 | 3개월+ | 색인 0건(2026-08-30) → 당장 불가, 장기 병행 |
| 5 | 카페·지식인·오픈채팅 | 수동 | 0 | 느림 | 광고글 강퇴 일상화, 지식인 상위노출 채택률60%+650건 |
| 6 | 유튜브 쇼츠 | 반자동 | 0 | 느림 | 링크는 설명란/고정댓글만, 100만뷰≈10~20만원, 상담형과 미스매치 |
| 보조 | 스레드·페북페이지·인스타·X | 자동 | 0 | — | §1~2 참조 |

### 3.1 당근 상세 수치
- CPC 최소 100원, 실운영 300~600원(서울·경기). 개인회생 업종: 당근 300원 이하 vs 네이버 검색 86,000원.
- 리드폼(앱 내 자동입력·제출만): 페이지 이동 없음, 채팅 문의 최활발 플랫폼이라 제출률 높음. 추천 5대 업종: 교육·상담·B2B·회원모집·의료.
- 최적화: 저녁 18~22시 집중(CPC −18%, CPA −25%) + 전환 낮은 지역 제외(CPC −15%) → 병행 시 CPC −30%, 전환율 1.7배, ROAS 2배. 반경 1~2km, 입찰 10~20%씩 상향, 실사진+동네명+이웃 말투.
- 마진: CPC 300~600 × 전환율 5~10% → 리드 3,000~12,000원 vs 애드릭스 CPA 1~3만P. 전환율 5%↓ 또는 승인율 50%면 적자.

### 3.2 KPI 원칙 — 리드단가가 아니라 CPQL
리드 15,000원·연결률 10% < 리드 25,000원·연결률 40%. "무료" 강조 소재는 리드만 많고 연결 안 됨. 최종 지표 = **승인 1건당 광고비**.
시장 단가: CPA 최저 5천·평균 1만·보험/분양 5만↑.

### 3.3 테스트 표준
매체별 10만원 × 5일 → DB 품질 비교 → 본 캠페인 전 최소 2주. 매체를 여러 개 열기 전에 측정 구조부터. 첫 실험은 `cpa_revenue_models_20260910.md` §6(이사스토리 × 당근 5만원 × 2일 × 저녁, 클릭 100↑/Lead 5↓=랜딩 실패 등 단계별 판별)과 일치.

## 4. 실행 순서

1. 계측 3종(픽셀·리드 수신·대사) 구현 — 채널 확장 전 선행
