# 검색 API 선택지 — Brave 외에 무엇이 있나

> 2026-09-15 · 조사 보고

## 먼저, 시장이 둘로 갈려 있습니다

| 갈래 | 무엇을 주나 | 우리에게 |
|---|---|---|
| **검색 엔진형** | 제목·주소·짧은 발췌 | 지금 쓰는 방식(Brave·네이버) |
| **에이전트형** | 정리된 본문 덩어리, 때로 요약 답변까지 | **자료 수집에 더 맞다** |

에이전트형은 **AI 에게 먹이려고 만든 검색**입니다. 결과를 긁어 정리하는
일을 그쪽이 대신합니다. 지금 우리가 "찾고 → 긁고 → 요약"하는 세 단계
중 뒤 둘을 줄여 줍니다.

---

## 값과 특징

1,000회 기준입니다. 글 한 편이 10회쯤 쓰니 **1,000회면 글 100편**입니다.

| 서비스 | 값 | 무료 | 성격 |
|---|---|---|---|
| **Parallel** | **$1** | — | 가장 쌈 |
| **Brave** (지금) | $5 | 월 $5 크레딧 | 검색 엔진형 · 클로드가 쓰는 곳 |
| **Exa** | $7 | 월 1,000회 | 에이전트형 · 본문까지 |
| **Tavily** | $8 | 넉넉함 | 에이전트형 · 요약 답변 포함 |
| **Serper** | 저렴 | 2,500회 | 구글 결과 원본 |
| **SerpAPI** | 높음 | 제한적 | 구글 결과 · 안정성 위주 |
| Gemini 검색 | ~$35 | — | 모델에 묶임 |

**Bing 검색 API 는 2025-08-11 에 종료**됐습니다. 구글 Custom Search 도
신규 가입이 막히고 2027-01-01 에 끝납니다. **남은 선택지는 위가 거의
전부**입니다.

---

## 우리 상황에서 실제로 의미 있는 것

### Tavily — 자료 수집에 가장 잘 맞습니다

한 번 부르면 **결과 + 정리된 본문**이 옵니다. 지금 우리는 네이버가 준
링크를 따라가 페이지를 긁고 그걸 다시 AI 로 요약합니다. Tavily 는 그
과정을 대신합니다.

- 요약에 쓰는 AI 호출이 줄어 **그쪽 요금이 내려갑니다**
- 크롤링 실패(차단·자바스크립트 페이지)가 사라집니다
- 무료 등급이 넉넉해 **써 보고 판단할 수 있습니다**

### Exa — 본문을 깊게 가져옵니다

의미로 찾는 검색이라 "이런 내용의 글"을 찾는 데 강합니다. 월 1,000회
무료. 값은 Tavily 와 비슷합니다.

### Parallel — 값이 5분의 1입니다

$1/1,000 로 Brave 의 5분의 1입니다. 발행량이 크게 늘면 의미가 생깁니다.
지금 규모에서는 Brave 와 월 몇 달러 차이라 **바꿀 이유가 약합니다.**

### Serper — 구글 결과 그대로

구글 검색 결과 원본을 줍니다. 네이버가 못 잡는 것을 구글이 잡는
경우에 씁니다. 2,500회 무료.

---

## 권고

**당장 바꿀 필요는 없습니다.** 지금 Brave + 네이버 + 법제처 셋이 돌고
있고, 월 100편까지 무료 범위 안입니다.

다만 **Tavily 는 한 번 견줘 볼 값어치가 있습니다.** 이유는 값이 아니라
**크롤링과 요약을 줄여 준다**는 점입니다. 지금 파이프라인에서 자료
수집이 느리고 자주 실패하는 지점이 거기입니다.

무료 등급이 있어 **키만 받으면 실제 글로 견줘 볼 수 있습니다.** 같은
제목으로 Brave 로 한 편, Tavily 로 한 편 만들어 자료가 어떻게 다른지
보는 방식입니다.

## 짚어 둘 것 — 검색을 바꿔도 문장은 그대로입니다

Brave 를 붙이고도 품질 차이를 크게 못 느끼셨다고 하셨는데, **예상되는
결과입니다.**

검색은 **글에 들어갈 재료**를 바꿉니다. 문장의 짜임새, 구성, 설득력은
**글을 쓰는 모델**이 정합니다. 지금 이사노트는 `deepseek-v4-flash` —
빠르고 싼 쪽에 맞춘 모델입니다.

재료를 좋은 것으로 바꿔도 같은 요리사가 만들면 요리는 비슷합니다.
**앞선 보고의 2번(모델)이 아직 남아 있습니다.** 품질 격차의 가장 큰
몫이 거기입니다.

정확성은 말씀대로 **지켜보셔야 합니다.** 법제처는 원문을 주므로 법
근거만큼은 확실히 나아집니다.
