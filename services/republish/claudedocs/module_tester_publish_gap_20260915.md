# 모듈 테스터 — 글쓰기·발행 반자동화에 필요한 것

> 작성 2026-09-15 · 코드 수정 없음, 정리 보고
> 선행: `docs/plans/test_workbench_plan.md`

## 0. 요약

수작업으로 하던 흐름(질문 고르기 → 글 쓰기 → 블로거 발행)을 모듈 테스터에
올리려면 **가져올 것 9가지**와 **먼저 메워야 할 공백 3가지**가 있습니다.

**공백 셋이 더 급합니다.** 이게 없으면 나머지를 만들어도 발행 버튼이 안
눌립니다.

| 공백 | 지금 상태 | 없으면 |
|---|---|---|
| **구글 계정 연결** | 이사노트에 **연결 안 됨** | 발행 자체가 불가 |
| **프롬프트 모듈** | 이사노트에 **하나도 없음** | 테스터에서 고를 게 없음 |
| **CPA 링크 등록** | 오퍼는 있으나 **링크가 비어 있음** | 버튼을 자동으로 못 넣음 |

## 2. 모듈 테스터로 가져와야 할 것 9가지

### 데이터 — 블로그 하나에 붙어 있는 값들

**① 표지 이미지 설정**
제목을 얹을 배경, 글꼴, 글자 크기·색, 여백. 이사노트는 이미 갖춰져 있어
그대로 씁니다. 테스터는 블로그를 고르면 이 설정으로 표지를 만듭니다.

**② 글 스타일**
소제목 색, 본문 크기, 표 색, 버튼 모양 같은 것들. 이사노트는 갖춰져
있습니다. **미리보기가 이 값을 써서 실제 모습으로 보여줍니다.**

**③ 이미지 업로드 키**
표지를 이미지 서버에 올려 주소를 받는 데 씁니다. 이사노트는 등록돼
있습니다.

**④ CPA 오퍼와 링크** ★공백
어떤 글에 어떤 상담 링크를 붙일지입니다. 지금은 오퍼가 등록돼 있지만
**링크 주소가 비어 있어** 버튼을 자동으로 만들 수 없습니다.
수작업에서 쓰는 이사용·청소용 두 링크를 오퍼에 넣어야 합니다.

**⑤ 구글 계정 연결** ★공백
블로거에 글을 올리려면 계정 인증이 필요합니다. **이사노트에 연결돼 있지
않습니다.** 등록된 계정이 하나 있지만 어느 블로그에도 물려 있지 않습니다.

### 모듈 — 테스터에 담을 것

**⑥ 생성 모듈(프롬프트)** ★공백
글을 어떻게 쓸지 정하는 모듈입니다. **이사노트에 연결된 모듈이 하나도
없습니다.** 테스터를 열어도 담을 게 없는 상태입니다.

여기에 수작업에서 쓰던 규칙을 넣어야 합니다.

- 1인칭 경험담 서술
- 표·목록 허용, 인용문 금지
- 도입에서 쟁점을 세우고 마지막에 정리 목록
- 상투어 금지 목록
- 본문 4,500~5,500자

**⑦ 키워드·제목 모듈** (선택)
질문에서 바로 제목을 쓰는 흐름이면 없어도 됩니다. 니치를 넓히려면
나중에 붙입니다.

### 기능 — 단독으로 불러올 것

**⑧ 근거 체크리스트**
지난주에 만든 것입니다. 제목을 확정하면 "무엇을 알아야 하나"를 정하고
항목별로 나눠 검색합니다. 수작업에서 제가 하던 판단이 이 자리입니다.
**기본은 꺼져 있어** 테스터에서 켜야 합니다.

**⑨ 지식iN·카페 질문 수집**
역시 지난주에 만들었고 테스터 화면에 이미 붙어 있습니다. 검색어를 넣으면
질문과 상황 신호가 함께 나옵니다.

## 3. 수작업과 시스템이 다른 지점 — 검색

**여기가 품질 차이의 남은 원인입니다.**

제가 수작업으로 할 때는 **웹 검색**으로 법령·뉴스·업계 자료를 찾습니다.
퇴거 청소 글의 통상손모 법리, 제주 화물의 성수기 구조, 반려동물 냄새의
요산 결정 같은 것들이 그렇게 나왔습니다.

시스템의 참조 수집은 **네이버 검색 API**를 씁니다. 지난주에 소스를 여섯
갈래(웹·뉴스·지식iN·카페·백과·전문자료)로 늘렸지만, **제가 쓰는 웹 검색과
같지는 않습니다.**

**당장은 이 차이를 안고 가야 합니다.** 다만 체크리스트가 항목별로 소스를
갈라 던지므로, 한 번에 뭉뚱그려 검색하던 것보다는 나아집니다.

## 4. 없는 기능 — 고지문·버튼 조립

수작업에서 매번 손으로 붙이는 부분입니다.

```
[고지문]  이 포스팅은 애드릭스 수익을 위해 작성되었습니다
[표지]    이미지 블록
[본문]
[버튼]    이사 견적 무료로 비교해보기
```

**시스템에는 이걸 통째로 조립하는 자리가 없습니다.** 부품은 흩어져 있습니다.

- 표지 이미지 블록 — 있음
- 버튼 모양(`button-link`) — 있음. 내부 링크용으로 쓰고 있습니다
- 상담 링크에 글 번호 붙이기 — 있음. 어느 글에서 눌렸는지 추적용입니다
- **고지문** — 없음
- **본문 끝에 상담 버튼 붙이기** — 없음

**정보성 글에는 고지문과 버튼이 둘 다 빠져야 합니다.** 지난주에 쓴
장기수선충당금·이사 후 할 일·집 보는 법·상가 원상복구 넷이 그랬습니다.
**글마다 켜고 끌 수 있어야 합니다.**

## 5. 순서를 정하면

| 순서 | 할 일 | 누가 |
|---|---|---|
| **1** | 이사노트에 **구글 계정 연결** | 사용자 (인증 클릭) |
| **2** | CPA 오퍼에 **이사·청소 링크 등록** | 사용자 또는 저 |
| **3** | 이사노트용 **생성 모듈 만들기** | 저 |
| 4 | 고지문·버튼 **조립 기능** | 저 |
| 5 | 테스터에서 **발행까지 연결** | 저 |

**1번은 제가 못 합니다.** 구글 인증은 브라우저에서 계정으로 로그인해
권한을 주는 절차라 사용자가 직접 해야 합니다. 블로그 설정 화면에서
구글 계정을 연결하시면 됩니다.

**2번은 링크만 주시면 제가 넣겠습니다.** 지금 쓰시는 두 주소면 됩니다.

**3번부터는 제가 진행합니다.**

## 6. 완성됐을 때의 흐름

```
테스터 열기
  → 이사노트 선택
  → 생성 모듈 담기 (체크리스트 켬)
  → 소스에서 지식iN 질문 검색 → 마음에 드는 것 선택
  → [실행]
        쟁점 잡기 → 항목별 검색 → 구조 → 본문
        → 상투어 검사 → 표지 생성·업로드 → HTML 변환
        → 고지문·버튼 조립
  → 미리보기에서 확인, 필요하면 본문 수정
  → [반영 — 발행대기글 저장] 또는 [즉시 발행]
```

지금 제가 손으로 하는 10단계가 **버튼 두 번**이 됩니다. 사람이 판단할
자리는 **질문 고르기**와 **본문 검토** 둘로 줄어듭니다.
