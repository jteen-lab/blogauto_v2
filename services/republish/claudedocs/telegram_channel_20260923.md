# 텔레그램 채널 — 발행 글·전자책·자동화툴 홍보 창구 검토

> 작성 2026-09-23 | 관련: `cpa_sns_channels_20260922.md`(X·스레드·인스타·페북 검토), `~/cheshirecat-app`(텔레그램 봇 운영 중)
> 질문: "텔레그램 채널이 무엇이고, blogauto 발행 글·추후 전자책·자동화툴 홍보에 쓸 수 있는가"
> 프로젝트 메모리 요약: `project_telegram_channel.md`

## 0. 결론

**유입 채널로는 부적합, 보유 고객 창구로는 적합.** 텔레그램에는 추천 알고리즘·탐색 피드가 없어 새 독자를 데려오지 못한다(= 색인 0 문제를 해결하지 못함). 반면 **링크 페널티가 전혀 없고 봇 자동 게시가 무료**라, 이미 확보한 사람에게 새 글·전자책·툴 업데이트를 보내는 그릇으로는 SNS 4종보다 낫다.

## 1. 채널의 정체

| 종류 | 성격 | 인원 | 비고 |
|---|---|---|---|
| **채널** | 관리자만 게시, 구독자는 읽기 — 일방향 방송 | **무제한** | 이 문서의 대상 |
| 그룹 | 모두 대화 | 20만 | 커뮤니티용 |
| 봇 | 1:1 자동응답 | — | cheshirecat-app이 이것 |

공식 사양(telegram.org/faq_channels):
- 공개 채널: `@username` + `t.me/이름`, **텔레그램 내부 검색에 노출**
- 비공개 채널: 초대 링크로만 입장
- 생성자가 직접 추가 가능 인원 **200명**(이후는 본인이 링크로 참여)
- **모든 게시물에 조회수 카운터**
- 관리자 서명, **토론 그룹 연결**(채널 글에 댓글), 봇으로 버튼 추가

## 2. 자동 게시 — 이 검토의 핵심

봇을 채널 관리자로 추가하면 Bot API `sendMessage`로 **무료 자동 게시**. cheshirecat-app이 이미 텔레그램 봇을 운영 중이라 추가 학습 비용 ≈ 0.

**한도**: 전역 약 30 msg/s · 단일 채팅 약 1 msg/s · 단일 그룹 20 msg/분. 429 응답 시 `retry_after` 준수(무시하면 쿨다운 누적 증가). 모든 API 메서드가 한도에 산입(sendPhoto·editMessageText 등 포함). 유료 브로드캐스트(1,000 msg/s)는 봇 잔액 1만 Stars 필요 — 우리 규모엔 무관.

**RSS 연동**: 네이티브 봇(RSS Bot, Feed Reader Bot) 또는 n8n/Make/Zapier 템플릿으로 코드 없이 "새 글 발행 → 채널 게시" 가능. blogauto는 이미 sitemap/RSS를 내보내므로 추가 개발 없이 붙는다.

## 3. 링크 제약 없음 — SNS 4종과 결정적 차이

| 채널 | 링크 제약 |
|---|---|
| X | 링크 포함 게시 $0.20/건, 비프리미엄 노출 ≈0 |
| 인스타 | API로 클릭 링크 불가(스토리 스티커 미지원) |
| 페북 페이지 | 본문 링크 월 2건(비 Meta Verified) |
| 스레드 | 본문 링크 시 노출 감소 → 첫 댓글 우회 |
| **텔레그램 채널** | **없음.** 본문 링크·미리보기·버튼 자유 |

홍보 목적만 보면 가장 자유롭다. `cpa_sns_channels_20260922.md`의 우선순위표에 "링크 자유" 열이 있다면 텔레그램이 유일한 O.

## 4. 치명적 약점 — 유입이 0에서 시작

**추천 알고리즘·탐색 피드·추천 팔로우가 전혀 없다.** 구독자 한 명 한 명이 직접 찾아 들어와야 한다. 성장 수단은 다섯 가지뿐:

1. 내부 검색 최적화 — 채널명·설명에 실제 검색어, 게시물 해시태그
2. 채널 디렉터리 등재
3. 외부 플랫폼에서 유입(블로그·크몽·커뮤니티)
4. 타 채널 교차 홍보
5. 텔레그램 Ads(유료)

업계 공통 평가: "10K까지 가능하나 빠른 해법은 없고 인내가 필요한 마케팅 채널."

→ **blogauto의 병목(검색 유입 0)을 해결하지 못한다.** 같은 문제를 하나 더 만드는 쪽에 가깝다.

## 5. 수익화 기능(부가, 2024-08 슈퍼채널 업데이트)

| 기능 | 조건 | 수령 |
|---|---|---|
| 광고 수익 분배 | 공개 채널 **구독자 1,000명↑** | 채널 노출 광고 수익 **50%**, Fragment 통해 TON, 출금 수수료 없음 |
| **Stars 유료 구독** | 특별 초대 링크 발급 | 월 구독료 — **전자책·툴 구매자 전용 채널에 직접 적용 가능** |
| Star 반응 | — | 100% 수령, TON 전환 |
| 봇 유료 미디어 | — | 이미지·영상 유료 판매 |

한국 제한은 명시 없음. TON → 원화 환전 경로는 별도 확인 필요.

## 6. 한국 시장·규제

- 2024 딥페이크 사태 이후에도 국내 이용자 증가. 다만 플랫폼 이미지가 나쁨(불법 창구 연상).
- **투자 정보 유료 채널은 규제 직결**: 2024-08 개정 자본시장법 — 유료회원 대상 일방향 조언은 유사투자자문업 신고, 양방향·1:1은 투자자문업 등록. 오픈채팅·텔레그램 유료 리딩은 명시적 불법. 투자 콘텐츠 채널은 신고 전 개설 금지.

## 7. blogauto 적용안

**쓸 수 있는 용도 3가지**
1. **보유 고객 재방문 창구** — 크몽 구매자·블로그 방문자·지인 등 이미 확보한 사람 모으기. 텔레그램은 "발견"이 아니라 "관계 유지" 도구.
2. **전자책·자동화툴 배포·지원** — 구매자 전용 비공개 채널에 업데이트 공지·파일 배포, Stars 월 구독으로 멤버십화. **가장 실용적.**
3. **신규 글 RSS 자동 게시** — 비용 0, 링크 페널티 0, 봇 재사용. 구독자가 없어도 손해 없음.

**권장 구조(2단)**
- 공개 채널 1개: 새 글 자동 게시 + 무료 정보. 채널명·설명에 검색어, 디렉터리 등재. 1,000명 도달 시 광고 분배 검토.
- 비공개 채널: 전자책·툴 구매자 전용, Stars 구독.

**하지 말 것**: 구독자 구매, 무관한 채널·그룹 도배(뉴스픽 홍보금지 100곳 사례 참조), 429 무시 자동 도배, 투자 정보 유료화(규제 선행).

**착수 시점**: 지금 당장 만들 이유는 크지 않다. 전자책·툴이 나와 "구매자에게 계속 전달할 것"이 생길 때가 적기. 다만 공개 채널 1개를 미리 개설해 `@` 이름을 선점하고 RSS를 붙여두는 것은 비용 0이라 지금 해도 손해가 없다.
