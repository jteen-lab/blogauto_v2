# CPA 제휴 마케팅 — 실제로 수익이 나는 세 가지 모델

> 작성 2026-09-10 | 앞 문서 `cpa_traffic_strategy_20260910.md` 의 후속
> 질문: "홍보할 플랫폼이 없어 보이는데, 그럼에도 수익 내는 사람들은 어떻게 내는가"

---

## 0. 앞 보고서의 전제가 틀렸다

앞 문서는 **"무료 채널에 콘텐츠를 올려 오가닉 유입을 만든다"** 를 전제로 채널을
훑었다. 그 전제에서는 막힌 것이 맞다. 그런데 **실제로 돈을 버는 사람들은 그
전제를 쓰지 않는다.** 수익 모델이 세 가지로 갈린다.

| 모델 | 유입을 어떻게 얻나 | 핵심 자산 | 우리 시스템과의 관계 |
|---|---|---|---|
| ① 유료 트래픽 아비트리지 | **광고를 사서** 되판다 | 랜딩 1장 + 소재 + 계측 | 글 자동생성과 거의 무관 |
| ② 바이럴 유통 | 블로그·카페·지식인 대량 노출 | 콘텐츠 생산량 + 상위노출 | **지금 시스템이 겨냥한 자리** |
| ③ 자기 트래픽 보유 | 커뮤니티·채널을 먼저 키운다 | 구독자·회원 | 장기, 단기검증 부적합 |

### 먼저 냉정한 분포

애드픽 공개 데이터 기준(2016년, 활성 회원 9만 5천 명):

```
연 1천만원 이상 수익자      106명 = 상위 0.1%
상위 106명 평균 수익        약 8천만원
최고 수익자                 7억 3천만원 (전체 지급액의 8%)
나머지 99.9% 평균           연 2만원
```

**"수익을 내는 사람"은 극소수이고, 그 극소수는 대부분 모델 ①이나 ③이다.**
모델 ②만으로 상위권에 간 사례는 드물다. 이 분포를 먼저 인정하고 설계해야 한다.

---

## 1. 모델 ① 유료 트래픽 아비트리지 — 당근 이야기의 정체

> "당근으로 광고 수익을 얻었다" = 당근에서 광고를 **사서** 자기 랜딩으로 보내고,
> 거기서 받은 DB를 CPA 수익으로 바꾼 것. **광고를 사서 되판 것이다.**

### 왜 하필 당근인가

| 조건 | 내용 |
|---|---|
| 진입 장벽 | **사업자등록 없이 개인도 광고 가능** |
| 단가 | CPC 300~600원(서울·경기 기준). 지역 사용자 수·경쟁 광고 수로 결정 |
| 경쟁 | 아직 광고 경쟁이 덜해 가성비가 좋다는 평가 |
| 타겟팅 | **위치·지역 타겟팅이 다른 매체보다 정확** |
| 계측 | 전문가모드 → 전환 추적 코드 발급 → 랜딩에 픽셀 설치. `ViewPage`(방문)와 `Lead`(신청) 2단계 측정 |
| 과금 | 클릭했을 때만 과금. 최소 2일 이상 집행 권장, 시간대 지정 가능 |

DB 마케팅 업계의 랜딩 제작 서비스(디비카트 등)가 **당근 전환추적 코드 연동
가이드를 따로 만들어 둘 정도로** 이미 표준 경로다. 텐핑도 마케터의 홍보 채널을
`바이럴(블로그·카페·지식인)` 과 `유상광고(메타·당근·카카오·네이버)` 로 나눠
안내하며, **당근을 유상광고 채널로 명시**한다.

### 수익이 나는지 계산해 본다

```
당근 CPC                    300 ~ 600원
랜딩 상담신청 전환율         5 ~ 10%
  → DB 1건당 광고비          3,000 ~ 12,000원
승인율 70% 가정
  → 승인 1건당 광고비        4,300 ~ 17,000원

애드릭스 CPA 단가            10,000 ~ 30,000P (= 원)
일반 CPA 시장 단가           5,000원 내외
```

**마진이 나긴 하지만 폭이 좁다.** 전환율이 5% 아래로 내려가거나 승인율이 50%면
곧바로 적자다. 그래서 이 모델은 **최적화가 전부**다. 보고된 개선 사례:

```
시간대 최적화 (저녁 18~22시가 CTR·전환율 모두 최고)   CPC -18%, CPA -25%
지역 세분화 (전환 낮은 지역 제외)                      CPC 추가 -15%
둘 다 적용                                             CPC -30%, 전환율 1.7배, ROAS 2배
```
다른 매체 대비 DB가 6배 수집되면서 DB 단가는 가장 낮았던 캠페인 사례도 보고된다.

### 이 모델이 우리에게 뜻하는 것

**콘텐츠 자동 생성과 거의 관계가 없다.** 필요한 것은 글 1,000편이 아니라
**잘 도는 랜딩 1장 + 소재 몇 개 + 정확한 계측**이다. 지금 시스템의 무게 중심과
다르다.

### 당근을 쓸 때 실제로 걸리는 것

- **동네생활에 홍보글을 올리면 신고·이용정지 대상.** 반드시 유료 광고 또는
  비즈프로필 경로로 간다
- 광고 심사는 대체로 24시간 내. 사전심사 + 사후 모니터링 + 사용자 신고 처리
- 업종에 따라 자격 확인을 요구(예: 과외는 재학증명서·신분증)
  → **금융·법률·의료는 더 엄격할 것으로 봐야 한다**
- 랜딩이 얇으면 심사에서 걸린다. `consult_page.py` 의 900자 하한과
  "바깥 링크를 다 없애도 쓸모 있는가" 판별 기준이 여기서 의미를 갖는다

## 2. 모델 ② 바이럴 유통 — 고단가 업종은 여전히 블로그·카페

개인회생/파산 DB 업계의 실무 보고가 명확하다.

> **페이스북·인스타 DB는 효율 문제로 아예 취급하지 않고, 블로그·카페에 집중한다.**

이유는 검색 유입의 **의도 강도** 때문이다. "개인회생 조건"을 검색한 사람은 이미
문제를 안고 있다. 반면 피드 광고로 들어온 사람은 흥미 단계라 승인율이 낮다.
DB 마케팅에서 잠재고객을 3단계(잘 아는 / 어느정도 아는 / 흥미만 있는)로 나누는
것이 이 얘기다.

고단가 업종일수록 이 격차가 커서, 법률·정책자금 쪽은 검색 기반 유입이 살아 있다.
**여기가 우리 시스템이 원래 겨냥한 자리다.**

다만 조건이 붙는다.

- 네이버는 2026년 7월 기준 광고 카페·광고글 단속을 강화 중
- 카페 운영원칙상 영리 목적 홍보글은 삭제·계정 차단 대상
- 네이버 블로그는 광고성 글 비율 30% 초과 시 저품질 위험
- **→ 자사 도메인(워드프레스) + 구글 검색이 우리가 통제할 수 있는 유일한 땅**

---

## 3. 모델 ③ 자기 트래픽 보유

오픈채팅방·카페·유튜브를 먼저 키우고 거기에 오퍼를 꽂는 방식. 상위 수익자
다수가 여기 해당하지만 **구축에 수개월~수년이 걸려 단기 검증에는 맞지 않는다.**
지금 단계에서는 선택지에서 뺀다.

---

## 4. 우리가 가진 오퍼별로 어디에 붙는가

| 오퍼 | 업종 | 1순위 채널 | 주의 |
|---|---|---|---|
| **이사스토리** | 생활 | **당근 지역광고** | 지역 + 즉시 니즈 = 당근에 가장 잘 맞음 |
| 현금사은품 인터넷가입 | 통신 | 당근 · 카페 | 경품 고지 규제(최대 48만원 한도 등) |
| 카바딜러 신차견적 | 자동차 | 당근 · 메타 | 지역성 있음 |
| 산지식물자원관리사 | 교육 | 블로그 검색 · 메타 | 자격증은 검색 의도 강함 |
| 법무법인 중정·서앤율 | 법률 | 블로그 · 카페 검색 | 변호사 광고 규정, 페북/인스타 DB는 효율 낮다는 업계 보고 |
| 야호스탁론 | 금융 | 제한적 | 금융광고 규제 강함. 단정·최상급 표현 규제 |
| 부산ㅎr늘안과 | 의료 | **사실상 막힘** | 의료법 제57조 사전심의 + 광고주 채널 금지 |

**검증 1순위는 이사스토리다.** 의료법·금융규제가 없고, 지역성과 즉시 니즈가
있어 당근과 맞고, 규칙이 27건으로 단순해 시스템 검증에 집중할 수 있다.

---

## 5. 전략 수정 — 시스템의 무게 중심을 옮겨야 한다

지금 시스템은 **"오퍼 → 규칙 → 제목 재고 → 글 대량 생성 → 발행"** 이다.
이건 모델 ② 전용 구조다. 그런데 모델 ②는 상위 수익자가 드문 경로이고,
우리 오퍼 중 절반은 그 경로가 막혀 있다.

모델 ①을 검증하려면 필요한 것이 다르다.

| 필요한 것 | 지금 상태 |
|---|---|
| 랜딩(상담 페이지) 1~2장 | `consult_page.py` **있음** — 900자 하한, 얇은 브릿지 판별 기준까지 |
| 대상 밖 사람 걸러내기 | `consult_page.py` `_eligibility_block` **있음** — 미승인 사유로 사전 안내 |
| 서브아이디 추적 | `subid.py` **있음** — `o12-p345-b7` |
| **클릭 계측** | **없음** — 우리 글/광고에서 나간 클릭 수를 모른다 |
| **전환 픽셀 연동** | **없음** — 당근 `ViewPage`/`Lead` 이벤트를 랜딩에 심을 자리 |
| **채널 기록** | **없음** — 어느 채널에 뿌렸는지 데이터 없음 |
| 네트워크 리포트 대사 | **없음** — 서브아이디로 전환을 우리 글에 붙이는 절차 |

**글 생성기는 이미 충분하고, 없는 것은 전부 계측이다.**

## 6. 제안하는 첫 실험

```
오퍼      이사스토리 (생활서비스)
채널      당근 광고 (전문가모드)
예산      5만원 / 지역 3곳 / 2일 / 저녁 18~22시
랜딩      consult_page.py 로 만든 상담 페이지 1장 + 당근 전환추적 코드
추적      랜딩 URL 에 subid.apply() 로 o3-p{post} 부착
```

측정하는 다섯 숫자와 출처:

```
노출        당근 리포트
클릭        당근 리포트          ← 광고비가 여기서 나간다
ViewPage    당근 픽셀
Lead        당근 픽셀 + 우리 폼
승인        애드릭스 리포트 (서브아이디로 대사)
```

**판정 기준을 먼저 정한다.**

- 클릭 100 미만 → 소재·타겟팅 실패
- 클릭 100 이상 + Lead 5 미만(전환 5% 미만) → **랜딩 실패**
- Lead 있음 + 승인 0 → 타겟팅 실패(대상 밖 사람을 불렀다)
- 승인 있음 → 승인 1건당 광고비를 계산해 단가와 비교 → 모델 성립 여부 판단

어느 단계가 실패했는지 구분되지 않으면 다음에 무엇을 고칠지 알 수 없다.

## 7. 정리

1. **막힌 게 아니라 모델이 다른 것이었다.** 무료 채널 오가닉 전제를 버리면
   당근·메타 같은 유료 트래픽 경로가 열려 있다.
2. **당근 수익담의 정체는 아비트리지다.** 광고를 싸게 사서(CPC 300~600원)
   CPA 단가(1~3만원)와의 차익을 남기는 것. 마진 폭이 좁아 계측과 최적화가 전부.
3. **분포는 냉정하다.** 애드픽 기준 99.9%가 연 2만원. 되는 사람은 극소수이고
   대부분 유료 광고를 운용하거나 자기 트래픽을 가진 쪽이다.
4. **우리 시스템은 글 생성이 아니라 계측이 부족하다.** 랜딩·서브아이디는
   이미 있고, 클릭 계측·픽셀·리포트 대사가 없다.
5. **첫 실험은 이사스토리 × 당근 5만원.** 의료 오퍼는 채널이 열린 뒤에 붙인다.
