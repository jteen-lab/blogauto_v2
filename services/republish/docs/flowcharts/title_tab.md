# 임시제목·정식제목 탭 순서도

> 계획서: `docs/plans/title_tab_workplan.md`

## 1. 임시제목 탭 — 섹션 구조

```mermaid
flowchart TD
    A[임시제목 탭] --> B{☑ 수집}
    A --> C{☑ 생성}
    B -->|켬| B1[수집 설정 열림]
    B -->|끔| BX[수집 안 함]
    C -->|켬| C1[생성 설정 열림]
    C -->|끔| CX[생성 안 함]

    B1 --> B2[시드 선택<br/>채택키워드/니치도메인/직접입력]
    C1 --> C2[L1 키워드 기반]
    C1 --> C3[L3 뉴스 시의성]

    B2 & C2 & C3 --> G[관문<br/>금지어→분류→유사도]
    G -->|통과| M[정식제목]
    G -->|미분류| Q[임시제목 = 회수 큐]

    note["키워드 모듈과 같은 원리.<br/>한 섹션만 켜면 그 기능 전용."]
    A -.- note
```

## 2. 수집 — 제목 수집과 도메인 추출을 분리

```mermaid
flowchart TD
    subgraph OLD["옛 방식 — 도메인이 방치된다"]
        direction TB
        O1[키워드 수집] --> O2[키워드로 제목 검색]
        O2 --> O3[제목이 속한 도메인 저장]
        O3 --> O4{목표 제목 수<br/>1,000개 채움}
        O4 -->|예| O5[사이클 종료]
        O5 --> O6["중단된 도메인은<br/>다시 꺼내지 않음"]
        O6 --> O7["도메인만 누적<br/>12만 건 중 0.02%만 처리"]
    end

    subgraph NEW["새 방식 — 두 기능으로 분리"]
        direction TB
        N0[제목 수집 모듈]
        N0 --> N1["☑ ① 제목 수집<br/>채택 키워드로 검색"]
        N0 --> N2["☑ ② 도메인 추출<br/>저장된 도메인에서 마저 추출"]
        N1 --> N3[제목 + 새 도메인]
        N2 --> N4["extract_status = partial<br/>인 도메인 우선"]
        N3 & N4 --> N5[관문]
    end

    OLD -.대체.-> NEW
```

### 2-1. 한 사이클 안에서의 판단

```mermaid
flowchart TD
    S[사이클 시작] --> A{② 추출 켜짐}
    A -->|예| B["partial 도메인에서 추출<br/>품질점수 높은 순"]
    A -->|아니오| C
    B --> C{① 수집 켜짐}
    C -->|아니오| Z[종료]
    C -->|예| D{미완료 도메인 수}
    D -->|> max_pending_domains| E[신규 수집 건너뜀]
    D -->|<= 임계| F[채택 키워드로 검색]
    F --> G[domains_per_cycle 개만]
    G --> H[도메인당 urls_per_domain 개만<br/>최신순]
    B & H --> I[금지어 필터 · 카테고리 분류]
    I --> J{활성 니치 대조}
    J -->|무관| K["표시만(기본) 또는 차단"]
    J -->|일치| T[임시제목]
    E & Z --> Z2[끝]

    note["필터·분류는 이미 있다.<br/>새로 붙는 것은 '니치 대조' 하나."]
    J -.- note
```

## 3. 도메인 대량 삭제 → 팝업 → 차단

```mermaid
flowchart TD
    A[사용자가 임시제목 삭제] --> B["도메인별 삭제 누계 +1<br/>(DB 에 남긴다)"]
    B --> C{누계 >= domain_delete_threshold<br/>기본 5회}
    C -->|아니오| Z[제목만 삭제]
    C -->|예| D["팝업: 이 도메인의 남은 제목 전체"]
    D --> E[전체 선택 → 선택 삭제]
    D --> F[전체 삭제 + 도메인 차단]
    D --> G[닫기]
    F --> H["niche_domains.is_blocked = true"]
    H --> I["① 수집 · ② 추출 양쪽에서 제외"]

    note1["비율(%) 기준은 쓰지 않는다.<br/>제목 100건인 도메인에서<br/>30건을 지워야 반응하게 된다.<br/>운영자는 3~5건이면 안다."]
    C -.- note1

    note2["자동 삭제가 아니다.<br/>여러 페이지를 넘겨 가며 하나씩<br/>지우지 않기 위한 수작업 보조."]
    D -.- note2
```

## 4. 재조합 — 정식제목 탭

```mermaid
flowchart TD
    A[정식제목 선택] --> B[재조합 실행<br/>스타일 선택]
    B --> C[AI 재조합]
    C --> D{유사도 검사}
    D -->|겹침| C
    D -->|통과| E["정식제목으로 저장<br/>recombined_from_id = 원본
    group_id = 원본 그룹"]
    E --> F["목록에 ♻ 재조합 배지"]

    G[생성 모듈이 제목 선택] --> H{recombined_from_id 있나}
    H -->|예| I[재조합 건너뛰고 그대로 사용]
    H -->|아니오| J[모듈 옵션대로 재조합]
    I & J --> K[글 생성]
    K --> L[그룹 전체를 used 로<br/>같은 소재 중복 발행 차단]
```

## 5. L3 뉴스 시의성

```mermaid
flowchart TD
    A[뉴스 수집] --> B["요지 추출<br/>'무슨 일이 있었나'"]
    B --> C[니치 키워드와 결합]
    C --> D[AI 제목]
    D --> E[관문]
    E --> F["정식제목 + expires_at"]
    F --> G{만료일 지남}
    G -->|예| H[재고에서 내림]
    G -->|아니오| I[사용 가능]

    note["원문 제목은 재고에 넣지 않는다.<br/>L2 각도 신호와 같은 원칙."]
    B -.- note
```

## 6. 확장 재조합 (참고 사항)

```mermaid
flowchart TD
    A[정식제목] --> B{연도·'최신'·'올해' 포함<br/>AND created_at 오래됨}
    B -->|예| C["① 최신성 갱신<br/>2024년 → 2026년"]
    B -->|아니오| D{candidate_id 있음}
    D -->|예| E["② 키워드 축 확장<br/>팬아웃 질문을 힌트로"]
    D -->|아니오| F[일반 재조합]
    C & E & F --> G[유사도 검사]
    G --> H[정식제목 저장 · 같은 그룹]

    note["①은 규칙으로 후보를 고를 수 있어<br/>먼저 구현한다.<br/>②는 candidate_id 연결이 전제."]
    D -.- note
```

## 7. 니치 자동 확장

```mermaid
flowchart TD
    A["미분류 제목 64,575건"] --> B[어휘 빈도 분석<br/>token_df 재사용]
    B --> C{분류표에 있나}
    C -->|있음| X[건너뜀]
    C -->|없음, 50건 이상| D["후보 목록<br/>'실비보험' 1,204건"]
    D --> E{AI 배치 제안 켜짐}
    E -->|아니오| F[사람이 하위주제 선택]
    E -->|예| G["AI: 어느 하위주제인가<br/>+ 근거 + 신뢰도"]
    G --> H{신뢰도 >= 0.6}
    H -->|아니오| I[보류함]
    H -->|예| J[승인 목록]
    F & J --> K[분류표에 키워드 추가]
    K --> L[재분류 → 'N건 회수됨']

    note["미분류는 쓰레기가 아니라<br/>분류표의 구멍 목록이다."]
    A -.- note
```

## 8. 분류표 변경 경로 — 누가 부르든 같은 통로

```mermaid
flowchart TD
    U1[사람: 화면] --> P
    U2[클로드 코드<br/>밖에서 호출] --> P
    U3[앱 내 AI 에이전트] --> P
    U4[스크립트] --> P

    P["POST /admin/taxonomy/plan<br/>계산만 한다"] --> Q["영향 미리보기<br/>회수 N · 재분류 M · 이탈 K"]
    Q --> R{사람 승인}
    R -->|아니오| Z[버림]
    R -->|예| S["POST /admin/taxonomy/apply"]
    S --> T[스냅샷 저장 + 감사 로그]
    T --> V[적용]
    V --> W{문제 발생}
    W -->|예| Y["POST /admin/taxonomy/rollback"]
    Y --> V2[복구]

    note["API 를 먼저 만들면<br/>엔진은 나중에 고를 수 있다.<br/>서버에 CLI 를 내장할 필요가 없다."]
    P -.- note
```
