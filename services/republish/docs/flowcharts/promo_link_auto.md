# 키워드로 링크를 고른다

## 지금 무엇이 빠져 있나

프롬프트 템플릿은 제목의 키워드로 **저절로** 갈린다(로테이션). 그런데
링크는 **사람이 고른 하나가 모든 글에 그대로** 붙는다.

이사 견적 글과 청소 글을 한 회차에 만들면 둘 다 같은 링크를 단다.

## 맞추는 방식은 이미 있다

프롬프트 로테이션의 키워드 조합을 그대로 쓴다.

    이사+견적  →  다이사 이사 가격비교
    이사+청소  →  이사/입주 청소 모두클린

`+` 로 묶은 낱말이 **모두** 제목에 있어야 걸린다. 여럿이 맞으면 더
구체적인 쪽이 이긴다. 템플릿과 같은 규칙이라 따로 배울 것이 없다.

## 흐름

```mermaid
flowchart TD
    A[질문·제목 고르기] --> B[실행]
    B --> C[제목의 키워드로<br/>템플릿 선택]
    C --> D[글 생성]
    D --> E[미리보기 열기]
    E --> F{링크를 어떻게}
    F -->|자동| G[제목의 키워드로<br/>링크 선택]
    F -->|직접 고름| H[고른 링크 고정]
    F -->|붙이지 않음| I[고지문·버튼 없음]
    G --> J[조립]
    H --> J
    I --> J
```

**템플릿과 링크가 같은 키워드를 본다.** 이사 견적 글에는 견적 링크가,
청소 글에는 청소 링크가 붙는다.

## 맞는 링크가 없으면

붙이지 않는다. 엉뚱한 링크를 다느니 없는 편이 낫다 — 정보성 글로
나간다. 화면에 그렇게 적는다.

## 블로그 전용

링크에 블로그를 박아 두면 **그 블로그를 담았을 때만** 목록에 보인다.
비워 두면 어느 블로그에서나 쓴다. 이사 링크가 요리 블로그 목록에
섞이지 않게 하는 장치다.

## 고친다

주소가 바뀌거나 키워드를 잘못 적었을 때, 지금은 지우고 새로 등록하는
길밖에 없었다. 지우면 그 링크로 나간 글과의 연결도 흐려진다.

목록의 링크마다 **고치기**를 둔다. 누르면 아래 등록 칸이 그 링크의 값
으로 채워지고, 등록 버튼이 **고치기 저장**으로 바뀐다. 칸을 새로 만들지
않는다 — 등록과 수정이 같은 칸을 쓰면 배울 것이 하나다.

```mermaid
flowchart TD
    A[링크 목록] --> B{무엇을}
    B -->|고르기| C[이 글에 붙일 링크로]
    B -->|고치기| D[등록 칸에 값 채움]
    B -->|빼기| E[목록에서 감춤<br/>쓴 글은 그대로]
    D --> F[값 고침]
    F --> G{저장}
    G -->|저장| H[PATCH · 목록 갱신]
    G -->|취소| I[칸 비움 · 등록 모드로]
    H --> A
    I --> A
```

**고르고 있던 링크를 고치면** 고른 상태도 새 값으로 따라간다. 버튼 문구를
고쳤는데 미리보기는 옛 문구인 채면 무엇이 맞는지 알 수 없다.

키워드를 지우면(빈 칸) 그 링크는 **자동 선택에서 빠진다.** 등록할 때와
같은 규칙이다.

## 자동이 기본이다 (2026-09-16 고침)

만들어 놓고도 쓰이지 않았다. 「퇴실청소 … 보증금 반환 기한」 에 이사
가격비교 링크가 붙었다 — 판정은 맞았는데 **판정을 부르지 않았다.**

지난번에 손으로 고른 링크가 브라우저에 기억돼 모든 글에 그대로 붙고,
자동을 쓰려면 시트를 열어 매번 다시 골라야 했다. 고른 적이 없으면
**자동**으로 시작한다. 손으로 고른 사람만 고정으로 남는다.

```mermaid
flowchart TD
    A[화면 열기] --> B{전에 고른 것}
    B -->|없음| C[키워드로 자동]
    B -->|자동| C
    B -->|링크 번호| D[그 링크 고정]
    C --> E[글마다 제목으로 판정]
    E --> F{맞는 링크}
    F -->|있음| G[붙임 · 무엇이 왜 붙었는지 표시]
    F -->|없음| H[안 붙임 · 정보성 글이라고 표시]
    D --> I[늘 같은 링크 · 이름 표시]
```

## 무엇이 붙었는지 보인다

자동은 글마다 결과가 다르다. 그런데 화면은 손으로 고른 링크 이름만
보여 주고, 자동일 때는 오히려 "정보성 글 — 버튼 없음" 이라고 적었다.
붙었는지 안 붙었는지조차 알 수 없었다.

조립한 서버가 **무엇을 어느 규칙으로 골랐는지** 함께 돌려주고, 화면은
그것을 그대로 적는다.

    자동 · 이사/입주 청소 모두클린 (퇴실+청소)
    자동 · 맞는 링크 없음 — 정보성 글로 나갑니다
