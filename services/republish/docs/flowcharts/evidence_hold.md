# 근거 등급과 보류 — 확인된 것만 사실로 쓴다

2026-09-07 실측: "AK론 대출 금리와 조건" 글에 우리은행 신용대출 정보가
공식 자료로 붙었다. AK론은 금감원 공시에 없고, 웹에서도 10년 전 글에서
"업체 실체를 알기 어렵다"는 말이 나온다.

**증명은 불가능하다.** 할 수 있는 것은 확인된 것과 확인 안 된 것을
섞지 않는 것이다.

## 등급 판정

```mermaid
flowchart TD
    T[제목] --> Y{YMYL 니치인가<br/>금융·보험·세금·의료·부동산}
    Y -->|아니오| PASS[등급 없음<br/>지금까지 하던 대로]

    Y -->|예| API{공식 API 에<br/>이 상품이 있나}
    API -->|있음| A["**A 확인됨**<br/>공시 수치를 쓴다"]

    API -->|없음| CO{제목의 회사가<br/>공시 목록에 있나}
    CO -->|확인됨·회사명 없음| WEB1{공식 도메인 자료<br/>1건 이상}
    CO -->|확인 못함| WEB2

    WEB1 -->|있음| B["**B 부분 확인**"]
    WEB1 -->|없음| WEB2{관련 자료 2건 이상<br/>+ 12개월 이내}

    WEB2 -->|충족| B
    WEB2 -->|미충족| C["**C 확인 불가**<br/>발행 보류"]

    B --> X{서로 다른 출처 2곳에서<br/>같은 수치가 나왔나}
    X -->|나옴| X1[그 수치만 사용<br/>'공개된 자료 기준' 명시]
    X -->|없음| X2[수치 전면 금지<br/>확인처만 안내]
```

## 회사 실재 확인

금감원 `companySearch` 로 공시 참여 회사를 받는다(2026-09-07 실측
은행 18 · 여신전문 48 · 저축은행 80 · 보험 20 · 금투 7 = **173곳**).

**이 목록은 제도권 전체가 아니다.** 목록에 없다고 불법업체가 아니며,
대부업·중개업일 수 있다. 그래서 글에는 "확인하지 못했다" 까지만 쓰고
등록 여부를 어느 쪽으로도 단정하지 않는다.

표기가 갈린다 — 목록에 "오케이캐피탈 ㈜" 와 "OK저축은행" 이 함께 있다.
영문 머리글자를 한글로, 한글을 영문으로 펴서 맞춘다. 반대로 한글
접두어가 더 붙은 것은 다른 회사다(**행복드림저축은행 ≠ 드림저축은행**).

## 수집 충분 기준 (YMYL)

| 조건 | 뜻 |
|---|---|
| 공식 API 적중 | 기관이 공시한 값 — 가장 강하다 |
| 공식 도메인 자료 | `.go.kr` `.or.kr` 금융사 공식 — 1차에 준한다 |
| 자료 2건 이상 | 한 곳만 있으면 그 글의 오류를 그대로 받는다 |
| 12개월 이내 | 금리·제도는 오래된 값이 틀린 값이다 |
| 수치 교차 확인 | 서로 다른 출처 2곳에서 같은 값이 나온 것만 쓴다 |

**블로그·카페만 있고 수치가 한 곳에서만 나오면 충분하지 않다.**

## 보류와 재시도

```mermaid
flowchart LR
    C[C 등급] --> H[보류 +1<br/>글은 만들지 않는다]
    H --> W[제목은 재고에 남는다]
    W --> R{다음 회차에<br/>다시 뽑힘}
    R --> E{이번엔 자료가<br/>충분한가}
    E -->|예| G[정상 생성]
    E -->|아니오| H2[보류 +1]
    H2 --> N{3회째인가}
    N -->|아니오| W
    N -->|예| L[(검토 목록)]
```

**삭제하지 않는다.** 지우면 우리가 놓친 잘못을 확인할 방법이 사라진다.
3회 보류된 제목만 목록에 올려 사람이 판단한다.

## 왜 3회인가

한 번은 그날 검색이 나빴을 수 있다. 두 번은 우연이 겹칠 수 있다.
세 번이면 그 주제에 **공개된 근거가 없다**고 보는 편이 맞다.
