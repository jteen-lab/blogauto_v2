# 유사도 매칭 개편 V4 — 설계서

> **상태**: 설계(미구현) | **작성일**: 2026-07-25 | **순서도**: `docs/flowcharts/similarity_matching_v4.md`
> **원칙**: 임베딩(ko-SBERT 등, 폐기됨) 미사용. 기존 구조 확장.

---

## 1. 배경 · 목표

### 문제 (현황 분석 결과)
- 임시제목→정식제목 이동 시 유사도 그룹핑이 헐거워, **의미가 같은데 글자만 다른 제목**이 별도 그룹이 되어 **중복 글 생성·발행**이 발생.
- 실측 예: `"말린 고구마줄기볶음 레시피 정월대보름 묵나물 건고구마순 삶는법"` vs `"말린 고구마줄기볶음 고구마순볶음 삶는법"` → 유사도 **74.7점**, 기준 75점 → **0.3점 차로 그룹 실패**.
- 이 그룹핑 약화가 **연결테스트 오류(중복 제목 크래시)** · **발행대기 카운트 불일치(1:N 매칭)** 로 번짐. 뿌리는 하나.

### 근본 약점 3가지 (수동 승격·데이터 모듈 공통)
1. **대표(representative)하고만 비교** — 속도 위해 도입. 그룹 비대표 멤버와의 유사성 놓침.
2. **글자(difflib) 기반 점수** — 길이 다르면 같은 주제도 점수 하락.
3. **75점 칼컷** — 경계값(74.7 등)이 갈라짐.

### 목표
- 의미가 같은 제목을 더 잘 묶되(정확도), **대량·고속** 유지(효율), **설정으로 조절** 가능, **기존 제목도 새 로직으로 백필**하되 **중복 재처리 없음(멱등)**.

## 2. 두 경로 비교 (사전 확인 결과)

| 항목 | 수동 승격(`/temp/promote`) | 데이터 이동 모듈 |
|---|---|---|
| 서비스 | `TitleTransferService.move_to_main` | **동일** |
| 그룹핑 | `_auto_group_title_sync` | **동일** |
| 점수 | `calculate_similarity_v3` | **동일** |
| 임계값 출처 | **하드코딩 75** | **설정** `similarity_threshold`(기본75) |

→ **코어 로직 동일, 차이는 임계값 출처뿐.** 공유 서비스이므로 한 곳 개선 = 양쪽 개선.

## 3. 설계 (4축)

### A. 설정 통일
- 유사도 관련 값을 **단일 설정 소스**로 이관: `threshold`, `gray_lower`, `gray_upper`, `ai_enabled`, `ai_model`, `blocking_enabled`.
- 저장 위치(택1, 설계 시 확정): ① 전역 설정 테이블/`settings` 키, ② 데이터 모듈 settings를 표준으로 삼고 수동 승격도 이를 참조.
- 수동 승격의 하드코딩 75 제거 → 동일 설정 참조. **결과: 로직+설정 모두 공유.**

### B. 회색지대 AI (단일 컷 → 밴드)
- 판정 규칙:
  - `S ≥ gray_upper`(예 80) → 자동 그룹
  - `S ≤ gray_lower`(예 68) → 자동 분리
  - `gray_lower < S < gray_upper` → **저렴 AI에게 "같은 주제인가?" 질의**
- 비용 절감:
  - **판정 캐시**: `(정규화(title_a), 정규화(title_b))` 키로 결과 저장 → 재질의 방지.
  - **배치 질의**: 회색지대 쌍을 모아 1회 호출.
  - **아주 저렴한 모델** 사용(짧은 이진 판정이라 충분).
- 실패/타임아웃 시 폴백: 보수적으로 "분리"(중복 위험 < 오병합 위험) 또는 설정으로 선택.

### C. 키워드 블로킹 (핵심 효율·정확 동시 해결)
- 새 제목의 **의미 토큰 전부**를 키로, **같은 토큰을 가진 후보만** 조회해 그 후보 전부와 비교.
  - → 전수비교 아님(빠름) + 대표만 아님(정확). **약점 1·2 동시 완화.**
- "키워드 미겹침 동의 제목" 우려 대응:
  1. **다중 토큰 매칭**(불용어 제외): "고구마" 하나만 겹쳐도 후보.
  2. **토큰 정규화 + 소규모 동의어 사전**(예: 삶는법=데치는법, 레시피=만드는법).
  3. 잔여 극소수는 **회색지대 AI + 주기적 전체 재점검**으로 보완.
- 구현 옵션(설계 시 확정): ① 역색인 테이블(title_id↔token), ② PostgreSQL 전문검색(GIN), ③ 토큰 컬럼 + 인덱스.

### E. 수동 재매칭 + 멱등성 (정식제목 탭)
- **UI**: 관리 항목에 "유사도 재매칭" 액션. 범위(전체/카테고리/선택), 모드(미처리만 기본 / 전체 강제), 진행률.
- **동작**: 새 파이프라인(C→점수→B)을 **기존 MainTitle**에 적용해 재그룹.
- **멱등성 — 버전 도장**:
  - `MainTitle.similarity_version`(문자열/정수) + `similarity_matched_at` 추가.
  - 그룹핑 시 **현재 버전 도장**. 재매칭 "미처리만" 모드는 `similarity_version != 현재버전 OR NULL`만 대상 → **이미 처리된 건 스킵(새 매칭 없음)**.
  - 로직/설정 변경 시 **현재 버전 상향** → 다음 재매칭에서 다시 전체 재평가.
- **안전장치**:
  - **미리보기 우선**(병합/이동/신설 예정 표시 후 확정).
  - **되돌리기**: run_id 단위 스냅샷(변경 전 group_id/representative).
  - **발행 이력 보존**: 발행된 제목의 매칭·카운트가 깨지지 않도록 그룹 병합/대표 재선정 규칙 명시.
  - 대량 → **celery 백그라운드**.

## 4. 데이터 모델 · 마이그레이션

신규/변경(alembic, upgrade 방향):
- `main_titles.similarity_version` `VARCHAR` NULL, index — 처리 버전 도장.
- `main_titles.similarity_matched_at` `TIMESTAMPTZ` NULL — 처리 시각.
- (C 선택 시) 토큰 역색인: `title_tokens(title_id FK, token VARCHAR, index(token))` 또는 GIN 전문검색 컬럼.
- (B) AI 판정 캐시: `similarity_ai_cache(key_hash PK, title_a, title_b, verdict BOOL, model, created_at)`.
- (E) 재매칭 스냅샷: `similarity_rematch_snapshot(run_id, title_id, prev_group_id, prev_is_rep, created_at)`.
- 설정(A): 전역 설정 키 또는 데이터 모듈 settings 표준화(마이그레이션 불필요할 수 있음).

> 규칙: 서버 배포 시 alembic 자동 실행 확인. 롤백은 항상 upgrade 방향(다운그레이드 금지).

## 5. 임계값 · 회색지대 튜닝 계획
- **병행 비교 기간**: 신·구 로직을 동시 계산해 로그만 남기고(그룹 변경 없이) 차이 수집.
- **골든셋**: 사용자가 "같다/다르다" 라벨링한 제목쌍 수십~수백개로 정밀도/재현율 측정.
- `gray_lower/upper`를 골든셋 기준으로 조정 → AI 질의량과 정확도 균형점 탐색.
- AI 질의 건수·비용 모니터링(회색지대 폭이 넓으면 비용↑).

## 6. 리스크 · 완화
| 리스크 | 완화 |
|---|---|
| 재매칭이 기존 그룹/발행 어지럽힘 | 미리보기+확정, 되돌리기 스냅샷, 발행 제목 보호 규칙 |
| AI 오판(회색지대) | 캐시+로그, 폴백 보수적 분리, 골든셋 검증 |
| 키워드 블로킹 누락 | 다중토큰·동의어·주기 재점검·AI 보완 |
| 대량 재매칭 부하 | 배치·백그라운드·진행률·상한 |
| 설정 변경 시 폭주 재매칭 | 버전 상향은 수동 트리거로만, "전체 강제"는 명시 확인 |

## 7. 단계적 도입
1. **P1 설정 통일(A)** — 수동 승격 하드코딩 제거, 공유 설정 참조.
2. **P2 밴드+회색지대 AI(B)** — 캐시·배치 포함.
3. **P3 키워드 블로킹(C)** — 역색인/전문검색 + 후보 전부 비교로 교체.
4. **P4 수동 재매칭+멱등(E)** — 버전 도장·미리보기·되돌리기.
5. 각 단계 **병행 비교·골든셋 검증** 후 반영.

## 9. 완료 기준(DoD)
- [ ] 문제 제목쌍(고구마줄기볶음 등)이 **같은 그룹**으로 묶임(회색지대 AI 경유 포함).
- [ ] 수동 승격·데이터 모듈이 **동일 로직+동일 설정** 사용.
- [ ] 재매칭 "미처리만" 재실행 시 **이미 처리분은 스킵**(새 매칭 0건) 검증.
- [ ] 대량(수십만) 재매칭이 백그라운드로 완주, 진행률·되돌리기 동작.
- [ ] 연결테스트 오류·발행대기 카운트 불일치 **재발 없음**(중복 제목 감소).
- [ ] 파일<500줄·함수<50줄, 타입힌트·docstring, 테스트 통과.
