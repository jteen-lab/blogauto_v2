# X5 — 구글 디스커버 대응 계획서

> 근거: `adsense_field_claims_review.md` §5·§6, `external_traffic_strategy.md`
> 착수 전 실측: 2026-08-28, 운영 블로그 11개 전수

## 0. 왜 지금인가

색인 실측(§`search_visibility_plan` §10)에서 확인된 상태는 두 층이었다.
**발견 실패**(사이트맵 미크롤)와 **색인 거부**(품질 판단). 둘 다 검색 결과 안에서의 싸움이다.

디스커버는 **검색 순위 경쟁 밖의 채널**이다. 공식적으로 최소 사이트 규모·도메인 권위
요건이 없고 주제 단위로 평가하므로, 색인이 막혀 있는 지금 유일하게 열려 있는 우회로다.

## 1. 실측 — 현재 디스커버 요건 충족도

| 블로그 | 플랫폼 | og:image | 크기 | `max-image-preview:large` |
|---|---|---|---|---|
| 굿팁꿀팁·꿀팁대백과사전·라이프인포·인생꿀팁·인포노트·잡학다식 | wp | 있음 | **500×500 ❌** | ✅ |
| 군타·머니조아·수작남·슈마즈·월드인포마스터 | blogger | **없음 ❌** | — | **❌** |

**11개 중 요건을 만족하는 블로그가 하나도 없다.** 디스커버 노출이 구조적으로 불가능한 상태다.

### 1.1 이미지 크기 — 원인은 템플릿 원본

- 전 블로그가 `image_mode = template` (AI 생성이 아니라 **업로드한 템플릿에 제목을 얹는 방식**)
- 템플릿 원본 11개가 **전부 500×500**
  (`media/blogs/*/template/template_*.png`)
- 업로드 경로의 `MAX_IMAGE_WIDTH = 1200` 은 **축소만** 한다. 작은 원본을 키우지 않는다.
- 즉 코드 결함이 아니라 **소재 규격 문제**다. 디스커버 요건은 가로 1,200px 이상.

> AI 모드(`image_mode=ai`)는 기본 16:9 → dall-e-3 1792×1024 / gpt-image-1 1536×1024 로
> 요건을 이미 만족한다. 문제는 template 모드에 한정된다.

### 1.2 블로거 — og:image 자체가 없음

블로거 5개는 `og:image` 도 `max-image-preview:large` 도 없다.
블로거 테마 설정(메타 설명 사용, 맞춤 robots 헤더)과 연관되며,
본문에 이미지가 있어도 **소셜/디스커버 카드용 메타가 나가지 않는다.**

## 2. 작업 항목

| # | 항목 | 성격 | 대상 |
|---|---|---|---|
| **X5-1** | **템플릿 이미지 규격 검사·경고** — 업로드 시와 설정 화면에서 1,200px 미만이면 경고 | 코드 | 전체 |
| **X5-2** | **디스커버 준비도 점검** — og:image 유무·크기, max-image-preview, 저자 신호를 발행 페이지에서 실측해 블로그별로 표시 | 코드 | 전체 |
| **X5-3** | 블로거 `max-image-preview:large` 메타 주입 | 코드 | blogger |
| **X5-4** | 저자 바이라인 확대 — 현재 11개 중 3개만 설정(군타·수작남·인포노트) | 설정 | 전체 |
| **X5-5** | **템플릿 이미지 교체(1,200px 이상)** | **사용자 조치** | 전체 |

X5-5 가 실제 병목이다. 코드로 대신할 수 없다 — 소재를 바꿔야 한다.
X5-1·X5-2 는 **그 사실을 사용자가 화면에서 알 수 있게** 만드는 일이다.

## 3. 설계 원칙

- **없는 것을 만들어내지 않는다.** 500×500 을 1,200px 로 확대하면 화질이 뭉개진다.
  자동 업스케일은 하지 않고 경고만 한다.
- **측정은 발행된 실물에서.** 설정값이 아니라 실제 페이지의 og:image 를 받아 크기를 잰다.
  (설정이 맞아도 테마·플러그인이 다른 이미지를 내보낼 수 있다 — 실제로 그랬다)
- 점검 실패가 발행·다른 기능을 막지 않는다.

## 4. 기대치

디스커버는 **노출을 보장하지 않는다.** 2026-02 코어 업데이트로 E-E-A-T 요건이 강화돼,
전문성·권위 신호가 약하면 요건을 갖춰도 피드에 뜨지 않는다.

X5 는 **자격 요건을 갖추는 일**이다. 지금은 요건 미달로 아예 후보에 오르지 못한다.
갖춘 뒤에도 콘텐츠 품질이 별도 관문으로 남는다([[monetization_strategy_2026]]).
