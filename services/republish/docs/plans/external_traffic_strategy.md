## 1. CPA와 애드센스 전략 분리

### 1.1 왜 섞으면 안 되는가

- 애드센스는 **페이지 단위**로 정책을 판정한다. CPA 제휴 링크가 주인 페이지에 애드센스를 함께 붙이면 "브리지 페이지 / 가치 없는 콘텐츠"로 분류될 소지가 크다. 현재 guntamoney가 2개월째 반려 중인 사유(`가치 없는 콘텐츠`)와 같은 계열이다.
- 애드센스 사이트 목록에 등록된 도메인은 하위 경로까지 검토 대상이다. 같은 도메인 안에 CPA 랜딩을 두면 승인 심사 자체가 흔들린다.

### 1.2 분리 축 3가지

**(A) 도메인 축 — 가장 중요**

```
애드센스 자산            CPA 자산
─────────────────       ─────────────────
doooit082.com 계열       cpa-landing.pages.dev (Astro/Cloudflare)
blogspot 블로그 4종      또는 별도 도메인
  ↳ 애드센스 코드 O        ↳ 애드센스 코드 절대 X
  ↳ 애드센스 사이트 등록 O  ↳ 애드센스 사이트 등록 X
```

CPA 도메인은 **애드센스 사이트 목록에 아예 등록하지 않는다.** 등록하지 않으면 심사 대상이 아니다.

**(B) 트래픽 축 — 두 번째로 중요**

| 유입 종류 | 애드센스 사이트 | CPA 랜딩 |
|-----------|----------------|----------|
| 검색 오가닉 | ✅ 유일하게 안전 | ✅ |
| SNS 자연 유입(핀터레스트 등 본인 계정) | ✅ 허용 | ✅ |
| 유료 광고(구글 애즈/네이버 광고) | ❌ **아비트라지 = 영구정지 위험** | ✅ 문제 없음 |
| 매크로·품앗이 클릭 | ❌ | ❌ |

Google은 "invalid, misleading, incentivized traffic"을 애드센스 광고로 보내는 것을 금지하며, 유료 트래픽 구매 후 광고 수익을 취하는 아비트라지는 광고 게재 제한(30일+ 수익 0) 또는 영구 정지로 이어진다. 포스트 부스팅 같은 소액도 트래픽 패턴으로 감지된다.
→ **광고비를 쓴다면 그 목적지는 반드시 CPA 랜딩이어야 한다.**

**(C) 콘텐츠 축**

| | 애드센스 블로그 | CPA 랜딩 |
|---|---|---|
| 목적 | 정보 제공(문제 해결) | 전환(신청/가입) |
| 길이 | 1,500~2,000자+ 심층 | 짧고 명확, 1스크롤 |
| 광고 | 애드센스만 | 제휴 링크만 |
| 상호 링크 | 본문 참고 링크 수준, `rel="sponsored"` 필수 | 애드센스 블로그로 역링크 X |

애드센스 블로그 → CPA 랜딩으로 링크할 때 `rel="sponsored"`(또는 `nofollow`)를 빼면 구글 링크 스팸 정책 위반이다. 이건 blogauto의 내부링크/외부링크 삽입 로직에 반영해야 한다. (→ 작업 항목 X1)

### 1.3 권장 운영 형태

```
[네이버 블로그]  ──브랜드/검색 유입──┐
[핀터레스트/스레드] ──소셜 유입──────┤
                                    ├─→ [애드센스 블로그] ─(sponsored 링크)→ [CPA 랜딩]
[구글/네이버 검색] ──오가닉─────────┘                                          ↑
                                                                              │
[유료 광고] ─────────────────────────────────────────────────────────────────┘
                                                    (유료는 CPA 랜딩으로 직행만)
```

핵심: **유료 광고 화살표가 애드센스 블로그를 통과하지 않는다.**

## 2. 광고비 자동 관리 — 가능성과 실효성

### 2.1 기술적 가능성: 가능하다

**네이버 검색광고**
- 공식 검색광고 API로 입찰가 변경이 가능하다. 엔비드, 비딩윈, 오토다비드, 비드스토리 등 상용 자동입찰 솔루션이 다수 운영 중이며 파워링크·쇼핑검색·파워컨텐츠를 지원한다.
- 즉 "원하는 순위를 최적가로 유지"는 이미 상품화된 영역이다. blogauto가 새로 만들 이유가 없다.

**구글 애즈**
- 스마트 비딩(tCPA / tROAS / 전환수 최대화)이 플랫폼에 내장돼 있다. 별도 개발 없이 목표만 넣으면 입찰은 구글이 자동 조정한다.

### 2.2 실효성: 자동화는 문제를 풀지 못한다

사용자가 중도 포기한 이유는 "**지출 대비 수익이 작다**"였다. 이건 입찰 관리의 문제가 아니라 **단위경제(unit economics)의 문제**다.

```
현재 구조:  광고비 지출 → 유입 → 애드센스 수익
            (클릭당 수백~수천원)   (클릭당 수십~수백원)
            ────────────────────────────────────────
            구조적으로 적자. 게다가 정책 위반.
```

자동입찰은 "같은 순위를 더 싸게" 만들어줄 뿐, 위 부등호를 뒤집지 못한다.
부등호가 뒤집히는 경우는 하나뿐 — **전환당 단가가 높은 CPA**다.

```
가능한 구조:  광고비 지출 → CPA 랜딩 → 전환 1건당 수천~수만원
              ↳ 전환추적이 있어야 손익 판단 가능
```

### 2.3 권고

| 단계 | 내용 | 시점 |
|------|------|------|
| 0 | **광고 자동화 개발 보류** | 지금 |
| 1 | CPA 랜딩 구축 + 전환 추적(GA4 이벤트 / 제휴사 postback) | CPA 진입 시 |
| 2 | 손익분기 CPA 산출 (전환당 수익 > 전환당 광고비 확인) | 최소 2주 데이터 |
| 3 | 그때 비로소 자동입찰 검토 — 그마저도 **자체 개발보다 구글 스마트비딩 + 네이버 상용 솔루션 사용이 합리적** | 3단계 |

**blogauto에 광고 입찰 자동화를 넣는 것은 우선순위 최하위로 둔다.** 넣더라도 "광고비 자동 조정"이 아니라 "**광고비/전환 데이터를 수집해 손익을 보여주는 대시보드**"가 먼저다.

## 3. 외부 유입 시스템화 — 4등급 분류

### 등급 A: 공식 API 자동화 (blogauto에 구현)

| 채널 | 상태 | 비고 |
|------|------|------|
| **핀터레스트** | 공식 Posting API 존재 | 검색 의도 기반 유입. "글 1편 = 핀 1개" 자동화 레버리지가 가장 큼. **신규 계정은 2주 워밍업 필요**(수동 1일 1핀 → 2 → 3, 월 조회 100+ 이후 API 연동) |
| **X(트위터) / 스레드 / 페이스북 페이지** | 공식 API | 유입량은 핀터레스트보다 작지만 비용 0 |
| **IndexNow (Bing/네이버)** | 공식 | 이미 `adsense_status_automation_plan.md` S1에 계획됨 |
| **사이트맵 신선도 관리** | — | S2 |

특징: 약관 위반 없음, 계정 리스크 없음, 애드센스 무효 트래픽 판정 대상 아님(본인 콘텐츠의 자연 홍보).

### 등급 B: 반자동 — 원고 생산까지만 시스템, 발행은 사람

| 채널 | 이유 |
|------|------|
| **네이버 블로그** | 글쓰기 API가 2020-05-06 종료. 자동 발행 수단이 없음 |
| **티스토리** | Open API 2024-02 종료 |

**blogauto가 할 수 있는 것**: 네이버 특성에 맞게 리라이팅한 원고 + 이미지 + 태그 + 발행 체크리스트를 **"발행 팩"으로 생성**해 복사/다운로드로 제공. 발행은 사용자가 직접.
이건 약관 위반이 아니고, 실제로 생산성의 대부분을 차지하는 부분이 원고 작성이므로 효과가 크다.

**주의**: 네이버 블로그에서 외부 사이트로 유도하는 링크가 많으면 저품질 판정 위험이 있다. 네이버 블로그는 "유입 통로"보다 **브랜드 검색·신뢰 축적** 용도로 쓰고, 링크는 글당 1개 이하·문맥상 자연스러운 위치로 제한한다.

### 등급 C: 구현하지 않음 — 계정 영구정지 위험

| 방식 | 위험 |
|------|------|
| 오토마우스·매크로로 네이버 블로그 자동 발행 | 비정상 활동 → 저품질/제재 |
| **지식iN 자동 답변 + 링크** | 스팸 적발 시 게시물 삭제 + 아이디 정지, 심하면 **주민등록번호 단위 영구정지**(복구 불가) |
| 카페 홍보글 자동 게시 | 즉시 강퇴·접근제한. 다계정 운용 시 연쇄 제재 |

"많이들 한다"는 것은 사실이나, 적발 시 손실이 비대칭적이다. 지식iN 영구정지는 명의 단위이므로 되돌릴 방법이 없고, 무효 트래픽으로 판정되면 **애드센스 계정까지 함께 위험해진다**. blogauto는 이 기능을 만들지 않는다.

### 등급 D: 절대 금지

- 유료 광고 트래픽 → 애드센스 페이지 (아비트라지)
- 클릭 품앗이 / 텔레그램·카톡 클릭 서클
- 트래픽 구매 서비스 ("2026년에 안전한 구매 트래픽 같은 것은 없다")

## 4. blogauto 반영 작업 항목

우선순위 순. 측정 → 자동 배포 → 반자동 지원 순서다. **측정이 없으면 무엇이 효과 있는지 알 수 없으므로 X0가 최우선.**

### X0. 유입 추적 기반 (선행 필수)
- 발행 URL에 **UTM 자동 부착** (source/medium/campaign = 채널/모듈/블로그)
- GA4 + 애드센스 리포트 API(이미 연동됨) 수집 → **채널별 유입·수익 대시보드**
- 산출물: "핀터레스트가 실제로 돈이 되는가"를 2주 안에 판정 가능
- 규모: 중 (모델 1개 + 수집 잡 + 대시보드 탭)

### X1. 외부링크 rel 속성 정책화
- CPA/제휴 링크 삽입 시 `rel="sponsored nofollow"` 자동 부착
- 애드센스 블로그 본문의 외부링크 개수 상한 설정
- 규모: 소

### X2. 소셜 배포 모듈 (핀터레스트 우선)
- 신규 모듈 타입 `social_distribute`
- 발행 완료 훅 → 핀 이미지 자동 생성(**blogauto 이미지 생성 기능 재사용, 세로 2:3**) → 보드 지정 → 핀 발행
- 계정 워밍업 상태를 모듈 설정에 두고, 워밍업 미완료 계정은 발행 차단
- 이후 스레드/X 확장
- 규모: 대

### X3. 네이버 발행 팩 생성기 (반자동)
- 기존 생성 글 → 네이버 톤으로 리라이팅 + 이미지 + 태그 + 링크 1개
- 화면에서 복사 / zip 다운로드
- 발행 여부를 사용자가 체크하면 X0 대시보드에 채널로 집계
- 규모: 중

### X4. (보류) 광고 손익 대시보드
- 네이버 검색광고 API / 구글 애즈 API에서 **비용만 읽어와** X0 대시보드에 합류
- 입찰 자동 조정은 넣지 않음
- CPA 전환추적이 붙은 뒤에 착수

## 5. 오늘 당장 손해 없이 할 수 있는 것

1. 애드센스 승인 대상을 10개 블로그가 아니라 **1~2개로 압축** (선행 보고서 결론)
2. 블로거 **메타 설명 사용 설정 ON**, 워드프레스 검색엔진 차단 해제 확인
3. 핀터레스트 계정 개설 후 **수동 워밍업 시작** (2주 뒤 X2가 바로 붙을 수 있도록)
4. CPA는 **별도 도메인 확보**부터 — 애드센스 사이트 목록에 절대 등록하지 않음
