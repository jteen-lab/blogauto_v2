# 니치(카테고리) 재설계 제안서

> 작성 2026-08-23 | 상태: 분석 완료 · 제안 | 수정 미진행
> 목적: **애드센스 수익 극대화** + 제목·니치 중복 타개
> 관련 [[niche_title_aeo_plan]] [[adsense_status_automation_plan]]

## 1. 현재 카테고리 전수 분석 (2026-08-23 실측)

주제 15개 / 세부주제 73행 / 정식제목 3,090건.

### 1.1 정리가 필요한 것 — 위생 문제

**(a) 테스트 잔재 13건이 운영 데이터에 섞여 있다**
- 건강/의학 하위: `0000` `333` `1111` `111_1111111111` `1` `2` `가` `다` `하` `테테테` `테스트01`
- 주제 레벨: `테스트`(하위 `1`,`121212`) · `원인+치료`(세부 없음) · `결혼/사랑`(세부 없음, 제목 0)
→ UI 카테고리 선택창에 그대로 노출되며 오선택 위험. **삭제 대상.**

**(b) 중복·유사 세부주제**
| 주제 | 중복 |
|---|---|
| 출산/육아 | `출산 준비`(21) ↔ `출산 준비`(32) — **완전 동일 이름** |
| 출산/육아 | `임신 준비`(19) ↔ `임신 준비/건강`(30) |
| 여행/관광 | `여행지`(26) ↔ `여행 정보`(27) ↔ `국내여행지`(25)/`해외여행지`(29) |
| AI/인공지능 `코딩`(17) | 컴퓨터/IT `코딩`(67) — **주제 넘어 중복** |
| 건강/의학 `건강 관리`(1) | 사실상 상위 개념(하위와 층위 불일치) |

**(c) 주제 경계 붕괴 — 가장 심각**
`생활 정보` 하위에 **`금융 정보` 164건**이 있다. 금융/대출(796) · 재테크(161)가
별도 주제로 존재하는데도 생활정보에 금융이 섞여 있어,
**생활정보 블로그들이 알게 모르게 금융 글을 쓰고 있다.**
`가격 비교`(98) · `제품 정보`(7)도 생활정보보다 쇼핑/리뷰 축에 가깝다.

**(d) 빈 껍데기 주제**
`의료`(병원/약국/한의원, 제목 0) · `지역/업체정보`(14) · `결혼/사랑`(0).
`의료`는 건강/의학과 중복 개념이라 통합 또는 재정의 필요.

### 1.2 재고 편중 — 깊이가 없다

| 주제 | 제목수 | 실질 세부주제 | 문제 |
|---|---|---|---|
| 생활 정보 | 1,143 | 7 | 전체의 **37%**, 단가 최하위 구간 |
| 금융/대출 | 796 | **1**(`대출 정보`에 796 전량) | 단가 최고인데 **깊이 0** |
| 여행/관광 | 370 | 1(`여행 정보`에 349) | 사실상 단일 덩어리 |
| 건강/의학 | 254 | 2(`질병 및 증상` 173) | 세부 17개 중 15개가 비어 있음 |
| 재테크 | 161 | 4(`토큰 증권` 100) | **토큰 증권 편중** — 수집 쏠림 |
| 취업/자격증 | 111 | 3 | 비교적 양호 |

**핵심 문제**: 단가가 가장 높은 금융/대출이 **세부주제 1개짜리 덩어리**다.
주제 권위(topical authority)는 "하위 질문을 모두 덮을 때" 형성되는데, 지금 구조로는
796건을 써도 깊이가 생기지 않는다.

### 1.3 단가 축의 공백
한국 시장 고단가 영역은 **금융·보험·법률·의료(시술/비용)·부동산**에 집중된다
(자동차보험 입찰가 수십만 원대, 교통사고 합의·이혼 상담, 지방흡입 비용 1~2만 원/클릭 등).

현재 카탈로그에 **보험 · 법률 · 부동산 · 세금 · 자동차**가 **아예 없다.**
대신 최하위 단가 구간(생활정보 $3~12)이 재고의 37%를 차지한다.

## 2. 제안 A — 정리(선행 작업)

| 조치 | 대상 |
|---|---|
| **삭제** | 테스트 잔재 13건, `테스트`·`원인+치료`·`결혼/사랑` 주제 |
| **병합** | 출산 준비(21→32) · 임신 준비(19→30) · 여행지(26→27) · AI 코딩(17→컴퓨터 67) |
| **이동** | 생활정보 `금융 정보`(164) → **금융/대출** 하위로 이동 |
| **이동** | 생활정보 `가격 비교`(98)·`제품 정보`(7) → 신설 `쇼핑/리뷰` |
| **통합** | `의료`(0건) → 건강/의학으로 흡수하거나 `병원·비용` 축으로 재정의 |

> 이동 시 이미 발행된 글의 카테고리 매핑이 바뀌므로, **blog_category_map 재정합**이 필요하다.

## 3. 제안 B — 신규/보완 니치

우선순위는 **단가 × 검색수요 × 진입난도**로 매겼다.
YMYL(돈·건강·법률)은 단가가 높은 대신 **E-E-A-T 요구가 엄격**하다는 점을 함께 표기한다.

### 3.1 최우선 (단가 최상위)
| 니치 | 세부주제 예시 | 단가 | 난도 |
|---|---|---|---|
| **보험** | 자동차보험 비교·실손보험·암보험·운전자보험·보험금 청구·해지환급금 | ★★★★★ | 높음(YMYL) |
| **금융/대출 심화** | 신용대출·전세자금대출·주택담보·중도상환·신용점수·연체·햇살론·정책금융 | ★★★★★ | 높음(YMYL) |
| **부동산** | 전월세 계약·전세사기 예방·중개수수료·취득세·재개발·청약 | ★★★★☆ | 높음 |

### 3.4 유지하되 축소
- **생활 정보**: 재고 1,143건을 버릴 수 없으나 **한 블로그 전속**으로 축소하고
  나머지 블로그의 주력에서 제외한다.
- **여행/관광**: 단가 중하위. 1개 블로그 전속으로 유지.
- **AI/인공지능·컴퓨터/IT**: 재고가 얕다(37/23). 당장 주력으로 쓰기 어렵다.

## 4. 제안 C — 블로그별 니치 전속 배정안

원칙:
1. **한 주제를 두 블로그가 주력으로 쓰지 않는다**
2. `doooit082.com` 계열 4개는 **같은 도메인**이므로 특히 겹치면 안 된다
3. 기존 재고·이름·현재 구성과의 연속성을 고려한다
4. 메인 도메인(유일하게 노출 중)에 **최고 단가 니치**를 배치한다

| 블로그 | 플랫폼 | 제안 주력 니치 | 근거 |

| **인생꿀팁** (doooit082.com) | WP | **보험** | 유일하게 노출되는 메인 도메인 + 최고 단가. 신뢰도 자산을 최고가 니치에 투입 |
| **꿀팁대백과사전** (fund.) | WP | **부동산/전월세** | 서브도메인명(fund)과 부합, 금융 인접 |

**법률/분쟁·의료 시술**은 단가 최상위지만 **YMYL 난도가 가장 높아** 이번 배정에서 제외했다.
저자 신뢰 신호(자격·실명·출처)를 갖춘 뒤 별도 블로그로 진입하는 것을 권한다.

## 5. 제안 D — 세부주제 깊이 기준

주제 권위는 **하위 질문을 얼마나 덮느냐**로 결정된다. 다음을 기준으로 삼는다.

- 전속 주력 니치: **세부주제 8~15개**, 각 세부주제당 제목 30건 이상
- 보조 니치: 세부주제 3~5개
- 현재 금융/대출은 세부 1개 → **최소 8개로 분할 필요**(3.1 예시 참조)

수집 단계에 **니치별 부족 세부주제 표시**를 넣어 보충을 유도한다(계획서 N3).

## 6. 실행 순서 제안

| 2 | **신규 니치 등록(제안 B 3.1~3.2)** | 주제·세부주제 골격만 먼저 |

## 7. 리스크
- **정리 중 데이터 손실**: 세부주제 이동·병합은 기존 제목의 소속을 바꾼다. 반드시 백업.
- **전환 공백**: 새 니치는 제목 재고가 0이다. 3번(수집)을 건너뛰면 배정 즉시 발행이 멈춘다.
- **YMYL 진입 실패**: 보험·부동산·세금은 단가가 높은 만큼 품질 요구가 높다. 저자 프로필·출처가
  부실하면 색인조차 안 될 수 있다(정보이득 지시문·저자 정합과 함께 가야 한다).
- **계절성**: 세금(연말정산 1월·종소세 5월)은 트래픽이 몰렸다 빠진다. 단독 주력은 위험.
- **기존 발행분과의 불일치**: 이미 생활정보로 수천 건을 발행한 블로그가 니치를 바꾸면
  과거 글과 주제가 어긋난다. 급전환보다 **신규 발행부터 점진 전환**을 권한다.
